# 공개 전 확인의 항목 수정

2026-11-05 · 사용자 확정: 수정은 현재 프로필에만 반영하며 다모아와 공통 이력 원본을 보존한다.

- 기존 이력과 다모아 활동이 같은 카드·제목·여백·구분선 양식을 사용한다.
- 자격·면허와 교육·연수의 보조 정보에는 기간 대신 주관·발급/교육 기관을 표시한다. 날짜 값은 보존한다. 주관이 없으면 날짜를 대신 노출하지 않는다.
- 다모아에서 가져올 때 개인 메모·파일·내부 상세 정보 전체를 복사하지 않고, 지정된 기관 입력란에서 주관 문자열만 복사한다. 기존 프로필의 미복사 주관은 소유자의 다모아 자료에서 보완해 보여주며 명시적인 프로필 저장 때 보관한다. 명시적으로 비운 주관은 다시 채우지 않는다.
- `+` 메뉴는 증빙자료 첨부와 수정으로 구성한다. 준비 중 순서 변경 메뉴는 제거하고 기존 드래그 정렬은 유지한다.
- 수정창의 반영은 미리보기 초안에만 적용한다. 취소는 초안을 변경하지 않는다. 프로필 저장과 공개프로필 업로드는 기존 별도 동작이다.
- 가져온 활동은 해당 프로필의 사본만 수정한다. 공통 이력은 원본을 보존하기 위해 이 프로필에서 원본 항목을 제외하고 수정 가능한 프로필용 활동 사본을 만든다. 원본의 인증·공개 증빙 권한을 사본에 자동 승계하지 않는다. 기존 증빙 심사는 항목 내용이 달라지면 이전 결과를 표시하지 않는다.
- 공통 이력의 프로필용 사본은 항목명·기관·날짜·설명 텍스트로 구성한다. 공통 이력 원본의 필드나 다른 프로필은 변경하지 않는다.

- 인증 사용자 권한으로 합성 비공개 프로필 저장/재조회 성공을 확인하고 트랜잭션을 전부 롤백했다. 적용 및 검증 전후 프로필 버전·다모아 원본의 지문과 검사 함수 실행 권한이 동일하다. 실제 회원 기록을 저장·공개·삭제하지 않았다.
- TypeScript 및 관련 23개 테스트, 기존 회귀 포함 40개 묶음/237개 테스트 통과. 별도 DB/인증 전용 환경을 요구하는 기존 테스트는 이 실행에서 제외했다.
- 로컬 로그인 미리보기에서 실제 저장된 활동의 기관 표시와 수정창 열기를 확인했다. 실제 회원 항목의 반영·저장·공개 버튼은 검증 편의로 누르지 않았다.
- 현재 웹코드는 미리보기 상태이며 커밋·운영 웹 배포는 아직 하지 않았다. DB 입력 검사 보완은 적용된 상태다.

## 항목 설정창 개편 · 2026-11-05

- 항목 이름·주관/기관·날짜/기간의 표시 여부를 고르고, 설명은 숨김/본문/더보기 중 선택한다. 배운 점·결과 입력란은 제공하지 않는다.
- 선택 결과는 창 안에서 바로 미리보기로 확인한다. 표시 문구 편집은 접힌 보조 영역에 두며, 취소는 선택을 반영하지 않는다.
- 설정은 현재 프로필 사본에만 적용하고 원본은 보존한다. 새 표시 설정에서는 배운 점을 공개 응답에 포함하지 않도록 준비했다.
- 관련 4개 묶음/23개 테스트 및 TypeScript 검사 통과. 로그인 브라우저에서 설정창 열기, 날짜 표시 선택, 설명 방식 변경, 취소 후 기본값 유지 확인 완료. 회원 자료 저장·공개는 수행하지 않았다.
- 최초 운영 적용은 자동 승인 검토에서 구체적 명시적 승인 부족으로 거절되었다. 이후 사용자가 해당 범위의 운영 DB 변경을 명시적으로 승인했다. 승인 후 `20261105142757_profile_item_presentation` 및 입력 검사 연산자 우선순위 보완 `20261105143043_profile_item_presentation_validation_precedence`를 적용했다.
- `PROFILE_PRESENTATION_STORAGE_ENABLED=true`. 새 표시 설정 저장과 공개 응답 필터링을 연결했다. 숨긴 이름·주관·날짜·설명 및 배운 점은 방문자 응답에서 제외한다. 모든 정보가 숨김인 활동은 공개 응답에 포함하지 않는다. 공개 첨부자료 목록도 숨긴 제목을 다시 노출하지 않으며, 원본 내용과 심사 스냅샷 비교는 유지한다.
- 인증 사용자 역할로 합성 비공개 프로필을 저장하고 원본 값 및 표시 설정 재조회를 확인했다. 격리 트랜잭션 안에서만 공개 대표 사본·합성 심사 결과를 구성하고 익명 역할로 숨긴 정보와 제목 미노출, 내부 도우미·초안 테이블 접근 차단을 확인했다. 전부 롤백했고 프로필 버전·다모아 기록·심사 결과 지문이 검증 전후 동일하다.
- 기존/신규 입력 허용, null·필수 불리언 누락·알 수 없는 모드/키 거부, 전체 숨김·선택한 설명 유지, 기존 초안 유효성 확인 통과. 최종 관련 23개 테스트와 TypeScript 검사도 다시 통과했다.
