# 공통 화면 기준

기준일: 2026-10-28 KST · 사용자 확정

- 공통 헤더: 높이 96px. 로고는 PT 검정 / Career #2563EB, 굵기 800, 좁은 자간. 모바일 30px, sm 이상 36px.
- 모바일에서는 로고 아래에 전문가 찾기, 오른쪽에 계정 메뉴. 좁은 화면에서 겹치지 않도록 간격을 조정하고 환영 문구는 lg 이상에서 표시한다.
- 랜딩 `/`의 헤더 숨김은 기존 확정 동작으로 유지한다. 그 외 모든 경로는 같은 SiteHeader를 쓴다.
- 공통 본문 컨테이너: 최대 폭 1240px, 좌우 여백 20px / lg 이상 32px, 본문과 바깥 배경 모두 흰색. 경로에 관계없이 좌우 테두리·그림자 없음.
- 개별 화면의 검색창·카드·폼·본문 폭과 보조 배경은 기능에 맞게 유지한다. 프레임 통일이 모든 카드의 배경을 없앤다는 뜻은 아니다.
- 전문가 탐색: 파란 성장 곡선은 글자·컴포넌트 뒤의 비상호작용 장식 배경. 검색·직군/지역/분야 다중 선택·더보기 데이터 로직 유지. 기존 홈의 프로필 카드는 기본 스타일 보존.
- 기존 Pretendard·Tossface, 공용 색 토큰, 라이트 테마를 유지한다.
- 변경 시 같은 기준을 제품 코드·현황판 프로젝트 기준·변경 이력에 함께 기록한다. 구현·배포와 검증 범위를 구분한다.

기준 파일: `components/SiteHeader.tsx`, `components/AppFrame.tsx`, `app/experts/`, `app/globals.css`.
