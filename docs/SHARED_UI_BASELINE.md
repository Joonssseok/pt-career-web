- 순서 편집 중 경력은 타임라인 세로선·원형 점·추가 들여쓰기를 제거하고 학력·교육과 같은 행 및 구분선으로 표시해 내부 레일과 본문 열을 맞춘다. 실제 공개 화면에는 기존 경력 타임라인을 유지한다.
