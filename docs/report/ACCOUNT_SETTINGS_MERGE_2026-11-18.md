# 계정 관리 메뉴 통합

- `/my/personal`을 통합 내정보 수정 화면으로 사용한다. 기존 기본정보 영역, 로그인 이메일·비밀번호·연락처, 네이버 연결, 이력서 다운로드, 계정 상태 안내, 로그아웃과 회원탈퇴 안내 진입을 모았다.
- 기존 PIN 확인을 유지하고 통과한 경우에만 계정 폼과 연락처를 조회·렌더한다. 새 권한이나 인증 설정 변경은 없다. 기본정보의 사진/이름/주소 저장 미연결 상태는 기존과 같다.
- 추천인·행사 코드는 `/my/referrals`로 분리했다. 사이드바·모바일 공통 메뉴·대시보드·마이페이지 개발 미리보기의 계정 관리 목록을 내정보 수정/추천인·행사 코드로 정리했다.
- 약관내역 메뉴와 화면은 제거하고 이전 `/my/terms` 주소는 내정보 수정으로 이동시킨다. 실제 이용약관/개인정보처리방침과 가입 동의 절차 및 기존 동의 기록은 유지한다.
- 회원탈퇴는 내정보 수정 하단 안내에서 기존 확인 화면으로 진입한다. 탈퇴 확인·신청·철회·정리 기능은 변경하지 않았고 실제 탈퇴를 실행하지 않았다. 취소 시 내정보 수정으로 돌아온다.
- 기존 `/my/account` 링크는 내정보 수정으로 이동하며 네이버 연결 오류 문맥을 보존한다. 기존 코드 등록 알림은 별도 코드 페이지로 이동한다. 신규 네이버 연결 callback과 가입 후 코드 오류 이동도 새 주소를 사용한다.
- 관련 6개 Jest 묶음/49개 검사, TypeScript 및 diff 검사 통과. PIN 미통과 시 연락처 조회/렌더 차단, 통합 화면 구성, 별도 코드 페이지, 옛 주소와 네이버 연결/가입 callback을 검사했다.
- 실제 로그인 브라우저에서 새 메뉴·별도 코드 조회와 `/my/account`의 `/my/personal` 이동, 통합 화면의 제목·탈퇴 링크·코드 패널 부재를 확인했다. 실제 이메일/전화/PIN/비밀번호 변경, 네이버 재연결 및 탈퇴 신청은 수행하지 않았다.
- 기능 구현 이후 사용자가 운영 배포를 요청했다. 최종 배포 결과는 PR과 현황판에 구분해 기록한다. 로컬 미리보기 주소: http://127.0.0.1:3002/my/personal 및 http://127.0.0.1:3002/my/referrals.
