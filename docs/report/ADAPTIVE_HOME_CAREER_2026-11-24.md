# 홈 이력의 자동 펼침 (2026-11-24)

사용자 요청에 따라 왼쪽 프로필 카드보다 오른쪽 요약이 짧으면 홈의 ‘주요 이력’을 ‘이력’으로 펼친다. 두 영역이 나란히 배치될 때만 비교하며, 세로 배치에서는 기존 요약을 유지한다.

- 소개·게시글·영상·증빙사진과 상단 탐색 영역을 포함한 오른쪽 요약 높이를 왼쪽 카드와 비교한다. 전체 이력을 펼친 후에도 같은 요약 높이로 판정해 접힘/펼침이 반복되지 않게 했다.
- 카드·본문·요약·탐색 영역의 크기와 화면 폭이 바뀌면 다시 측정한다. 실제 펼쳐진 이력은 높이 제한이나 내부 스크롤을 추가하지 않는다.
- 기존 이력 탭의 렌더링과 이미 전달된 공개 자료를 재사용한다. 항목·날짜·공개 설정·저장 순서·증빙 연결을 새로 추정하거나 조회하지 않는다. 원래 이력 탭과 증빙사진 모아보기는 유지한다.
- 펼쳐진 홈의 복사본은 검색 인덱스에서 제외한다. 숨겨진 요약은 화면·접근성 트리와 키보드 탐색에서 제외하되, 높이는 계속 측정할 수 있게 둔다.
- 저장·공개 설정·운영 DB 변경·커밋·푸시·앱 배포·온라인 현황판 게시는 하지 않았다.

## 검증

- 자동 펼침·긴 본문 요약 유지·반복 측정 안정성·콘텐츠 증가/감소·카드 높이 변경·세로 배치·원래 이력 검색 연결을 포함해 관련 3개 검사 묶음 24개 통과. 타입 검사 통과. 별도 검토에서 측정·관찰·검색 제외 경로의 차단 문제 없음.
- 실제 로컬 프로필에서 왼쪽 카드 약 1165px, 오른쪽 요약 약 945px일 때 이력 14개가 홈에 표시됨을 확인했다. 전체 이력의 순서와 제목은 이력 탭과 동일하다.
- 실제 프로필 검색에서 Myofascial 항목이 1건만 검색되고, 원래 이력 탭의 항목으로 이동하는 것을 확인했다.
- 폭 375px에서 요약으로 전환되며 가로 넘침이 없음을 확인했다. 임시 화면 폭은 확인 후 원래대로 복원한다.
