# 콜드스타트 & 전문가 온보딩 신뢰도 개선 구현 보고

**작성일**: 2026-08-10
**근거 문서**: 수정기획서 「콜드스타트 & 전문가 온보딩 신뢰도 개선」(2026-08-10, 페르소나 시나리오 테스트 기반)
**브랜치**: `feat/cold-start-trust-onboarding`
**범위**: 프론트엔드 카피·상태 처리만. DB 마이그레이션·RLS 변경·신규 API 없음 (기획서 원칙 준수)

## 1. 구현 내역

### 1.1 [High] Experts 콜드스타트 — `app/experts/page.tsx`

- 공개 전문가 수가 **10명 미만**(`COLD_START_THRESHOLD`)이면 목록 상단에 안내 배너 노출:
  > "PT Career는 이제 막 시작했어요. 지금 합류하는 전문가는 초기 멤버로 가장 먼저 눈에 띕니다."
- 임계치 판정은 목록과 동일한 소스인 `public_expert_list` 뷰의 `count`로 수행 (필터 결과 수와 혼동 방지). anon 롤로 count 쿼리 정상 동작 확인 완료 (현재 prod 공개 전문가 2명).
- 목록 하단에 **"전문가로 등록하기" CTA 카드** 상시 삽입 — ExpertCard와 같은 레이아웃(아바타 자리에 + 아이콘, dashed border)으로 목록 아이템과 같은 톤 유지. 링크는 랜딩과 동일하게 `getNextOnboardingStep()` 결과를 사용 (비로그인 → `/signup`, 작성 중 → `/expert/edit`, 완료 → `/my`).
- 빈 결과 상태에서도 배너 + CTA 카드가 함께 보여 "비어있음"이 아니라 "초기 단계"로 읽히도록 함.

### 1.2 [High] 가입 전 기대치 설정 — `app/signup/signup-form.tsx`

가입 폼 상단에 안내 카드 1개 추가 (신규 화면 없음 → CTO 승인 불필요 범위):

1. 가입 후 프로필 작성 — 약 5분
2. 프로필 사진과, 경력 또는 자격·면허 1개가 필요해요
3. 업로드하면 바로 공개돼요 (자격증 증빙 파일만 관리자 확인 후 배지 표시)

하단에 소비자 분기 안내: "전문가를 찾고 계신가요? 가입 없이 둘러볼 수 있어요" (→ `/experts`).

### 1.3 [Medium] 랜딩 CTA 위계 전환 — `app/page.tsx`

- "전문가 프로필 만들기"를 **Primary**(파란 배경)로, "전문가 찾기"를 **Secondary**(외곽선)로 전환하고 순서도 교체. 기존 버튼 스타일 그대로 재사용, 신규 컴포넌트 없음.
- 원복 조건(공급 목표치 도달 시)을 코드 주석으로 명시.

### 1.4 [Low] 로그인/가입 구분 안내 — `app/login/login-form.tsx`

- 로그인 타이틀 아래 한 줄 추가: "전문가 프로필 관리를 위한 로그인이에요. 전문가 찾기는 로그인 없이 가능해요." (전문가 찾기 링크 포함)
- 가입 쪽 구분 안내는 1.2 카드에 통합 (기획서 권고대로 별도 작업 미분리).

## 2. 기획서와 실제 제품의 차이 (구현 중 판정한 사항)

### 2.1 필터 "준비 중" 비활성화 — **구현하지 않음 (이미 해결됨)**

기획서 2.1-②는 "지역/분야 필터가 로딩 상태에서 멈춘다"는 관찰에 기반하나, **현재 main에는 다중선택 상세검색 필터(PR #63/#65/#69)가 이미 머지되어 정상 동작**함. 코드 전수 확인 결과 필터가 "불러오는 중..."에서 멈추는 경로는 존재하지 않음('더보기' 버튼 로딩 텍스트뿐). 테스트 시점의 구버전 배포를 관찰한 것으로 판단 — 메모리에 기록된 "prod drift" 패턴과 동일. 필터를 비활성화하면 오히려 동작하는 기능을 죽이는 것이므로 **미적용**.

### 2.2 승인 절차 카피 — **기획서 문구 대신 실제 플로우 반영**

기획서 2.2는 "제출 후 관리자 검토 → 공개 전환 (평균 처리 기간 명시)"를 제안했으나, 현재 제품의 실제 플로우는 **업로드 즉시 공개, 자격증 증빙 파일만 관리자 검토 후 배지 표시**임 (`EditForm.tsx` StatusBanner 문구로 확인). 존재하지 않는 검토 대기 기간을 안내하면 오히려 신뢰를 깎으므로, 가입 안내 카드는 실제 플로우 기준으로 작성함.

## 3. 검증 결과

- 로컬 dev 서버(`pnpm run dev`)에서 4개 화면 모두 렌더링 확인:
  - `/` — CTA 순서·위계 교체 확인 (computed style로 Primary/Secondary 전환 검증)
  - `/experts` — 콜드스타트 배너 + 하단 CTA 카드 + 빈 상태 공존 확인
  - `/signup` — 기대치 카드 3단계 + 소비자 분기 링크 확인
  - `/login` — 안내 문구 + 전문가 찾기 링크 확인
- 콘솔 에러 없음, `tsc --noEmit` 통과.
- prod DB(`public_expert_list`): anon 롤 count 쿼리 정상 (2명 → 배너 노출 조건 충족).
- `next lint`는 리포에 ESLint 설정이 없어 대화형 프롬프트로 실행 불가 (기존 상태, 이번 변경과 무관).

## 4. CTO 확인 필요 사항

1. **CTA 원복 기준**: 랜딩 Primary 원복 및 콜드스타트 배너 임계치(현재 10명)가 launch gate 수치와 맞는지. 배너는 임계치 도달 시 자동 소멸, CTA 위계는 수동 원복 필요.
2. **"약 5분" 카피**: 실측값 아님. 프로필 작성 단계(경력/자격 입력 폼)의 실계정 재검증(기획서 §4) 때 함께 확인 권장.
