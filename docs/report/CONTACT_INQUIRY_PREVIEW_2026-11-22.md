# 연락·문의 안내 — 미리보기 및 저장 연결

## 2026-11-23 저장 연결 (후속 사용자 요청)

- 후속 화면 정리: 기본정보의 ‘현재 근무지 선택’, 저장된 기관 정보와 다모아 바로가기 영역을 제거했다. 주요 활동 지역 다음에 연락·문의 안내가 이어진다. 기존 `currentWorkplace` 저장값과 공개 화면은 이번 화면 제거로 변환하거나 삭제하지 않는다. 배포하지 않았다.

- 프로필별 선택 JSON `contactInquiry`에 문의 링크·버튼 문구·전화·이메일·선택 위치·상세주소·개별 공개 여부를 함께 저장한다. 기존 자동 저장/지금 저장/다시 불러오기 경로를 사용한다. 로그인용 연락처를 자동 복사하지 않는다.
- 기존 초안은 해당 선택 필드 없이 계속 저장할 수 있으며, 화면을 열기만 해서는 새 필드를 저장하지 않는다. 주소 선택 해제는 다른 연락처를 보존하며 주소·상세주소·지도 공개를 함께 비운다.
- 서버와 DB에서 허용된 키·타입·문자 수·URL·전화·이메일·좌표·주소 일치를 검증한다. 비공개 값도 입력 검증을 거치며 임의 추가 키는 거부한다.
- 서버 공개 응답은 별도 `contact_inquiry` 필터를 사용한다. 주소와 지도 공개는 독립이며 지도만 공개할 때는 좌표만 전달한다. 저장된 전체 연락 객체·비공개 주소·상세주소·업체명을 공개 응답에 섞지 않는다.
- 명시적 빈 연락 설정은 이전 연락 버튼으로 되돌아가지 않는다. 기존 필드가 없는 프로필만 종전 연락 표시를 유지한다.
- 운영 DB에는 선택 필드 검증과 공개 필터 함수만 연결했다. 새 테이블·기존 권한/RLS 변경·자료 변환/삭제·게시 실행은 없다. 기존 공개 조회 함수의 정의와 권한은 동일하다. 앱 배포·커밋·푸시·병합·온라인 현황판 게시는 하지 않았다.
- 복구 파일은 공개 연락 카드 기능만 끄며 저장된 연락 초안은 보존한다. 명시적 연락 설정은 빈 공개 객체를 유지해 이전 연락 버튼이 다시 나타나지 않게 한다. 기존 권한과 편집 호환성은 유지한다.
- 검사: 관련 Jest 7개 묶음 50검사, 타입 검사, SQL 격리 258검사 통과. 소유자 저장/타인 접근 거부/익명 접근 거부/공개 조합/초안과 게시 내용 분리/기존 자료 보존/복구를 검사했다. 운영에서는 합성 값으로 필터 및 익명 실행 차단을 확인했다. 적용 전후 보안 진단 항목과 건수는 동일하며 기존 P0-10 후속 조치 완료를 의미하지 않는다.
- 실제 작성창에서 기존에 미리보기로 선택했던 근무기관의 네이버 검색 결과를 다시 선택하고 주소/지도 공개를 켜 비공개 초안에 저장했다. ‘프로필을 저장했습니다’ 확인 후 새로고침하여 선택 위치와 두 공개 설정이 유지되는 것을 확인했다. 문의 링크·전화·이메일은 임의로 채우지 않았으며 게시 버튼은 누르지 않았다. 상세주소 값과 개별 연락처의 저장·복원은 합성 값 자동검사로 확인했다.
- 운영 환경의 검색 키 연결과 앱 배포는 남아 있다. 현 단계에서 실제 운영 사이트 화면은 변경하지 않았다.

## 이전 미리보기 단계 (저장 연결 전 기록)

- 실제 프로필 작성창의 기본정보에서 문의 링크·버튼 문구·전화·이메일·주소를 선택 입력한다. 각 항목은 기본 비공개이며, 왼쪽 카드 하단에 공개 선택한 유효 항목만 표시한다.
- 네이버 업체명 검색은 로그인 확인 후 서버에서 NAVER API HUB 지역 검색 API를 호출한다. 검색 키는 서버 전용 로컬 설정에 두며 응답·로그·Git에 포함하지 않는다. 지도 키는 기존 공개용 설정을 유지한다.
- 주소 검색은 기존 네이버 Maps Geocoding을 사용한다. 결과를 선택한 뒤 상세주소를 별도로 입력한다. 상세주소는 네이버 검색에 전달하지 않는다.
- 주소 텍스트 공개와 지도 공개는 독립 설정이다. 지도에는 선택한 기본 주소의 좌표만 사용하고, 주소 비공개 시 상세주소·주소 텍스트를 카드나 지도 접근성 이름에 삽입하지 않는다.
- 연락·위치 상태는 저장/게시 내용과 분리된 화면 상태다. 새로고침 또는 다른 프로필로 전환하면 초기화한다. 운영 DB·게시 자료·운영 API 설정·배포 변경은 없다.
- 확인(2026-11-23): 관련 14검사 및 타입 검사 통과. 실제 네이버 주소 검색 결과 선택 및 지도 렌더링, API HUB 업체명 검색 결과 선택을 확인했다. 상세주소 입력, 주소 비공개/지도 공개 및 주소 공개/지도 비공개를 실제 작성창에서 확인했다. 프로필 내용은 저장·게시하지 않았다.
- 사용자가 API HUB 약관/제3자 제공 안내를 직접 확인하고 지역 검색 전용 앱을 등록했다. 인증 정보는 사용자가 숨김 입력을 통해 로컬 비공개 설정에만 저장했다. 일회성 입력 화면은 확인 후 종료했다. 기존 지도·로그인 키를 교체하거나 폐기하지 않았다.
- 신규 검색 연결은 2026-07-31 이후 이관된 현행 API HUB 주소·인증 헤더를 사용한다. 구형 개발자센터 주소로 자동 재시도하지 않는다.
- 당시 남은 작업: 별도 저장/공개 연결. 위 후속 요청으로 저장 연결을 진행했으며 운영 환경의 검색 키 연결과 앱 배포는 미수행이다.
