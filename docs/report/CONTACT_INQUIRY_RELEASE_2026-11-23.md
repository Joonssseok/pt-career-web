# 연락·문의 안내 및 프로필 기본정보 정리 릴리스

사용자가 지금까지 확정한 수정의 커밋·푸시·병합·운영 배포와 현황판 기록을 요청했다.

- 기본정보에 선택 입력 연락·문의 안내를 제공한다. 문의 링크·버튼 문구·전화·이메일·네이버 선택 위치·상세주소·개별 공개 설정을 각 프로필 초안에 함께 저장한다.
- 주소와 지도 공개는 독립 설정이다. 비공개 초안 저장은 게시하지 않으며, 명시적으로 게시한 항목만 서버가 추려 전달한다. 지도만 공개할 때는 좌표만 반환한다.
- 네이버 업체 검색은 로그인된 작성자만 서버 전용 연결로 호출한다. 주소 검색은 네이버 Maps를 사용하며 상세주소는 검색에 보내지 않는다. 운영 연결 설정은 비밀값을 출력하거나 Git에 넣지 않는 별도 경로로 적용한다.
- 기존 현재 근무지 선택 영역을 기본정보에서 제거하고 연락·문의 안내로 이어지게 한다. 저장된 예전 근무지 자료는 삭제하지 않는다.
- 프로필 삭제는 카드 바깥 좌하단의 작은 텍스트 버튼으로 이동한다. 확인창과 본인/대표 프로필 보호는 유지한다.
- 외부 링크 안내 명칭과 로고 크기를 정리하고 공식 제공 이미지 파일을 사용한다. 출처는 `public/brands/SOURCES.md`에 기록한다.
- 저장 검증과 공개 필터 DB 함수는 앞선 실제 저장 연결 요청으로 적용했다. 기존 테이블/RLS/기존 함수 권한을 변경하거나 사용자 자료를 변환·삭제하지 않았다. 공개 조회 함수는 기존 정의를 유지한다.
- 관련 화면·저장 검사 50개 및 타입 검사, 격리 SQL 258검사를 통과했다. 실제 로컬 작성창에서 선택 주소·두 공개 설정의 초안 저장과 새로고침 복원을 확인했다. 연락처 임의 입력·게시·삭제를 운영 확인용으로 수행하지 않는다.
- 전체 검사 결과와 배포의 PR·커밋·운영 배포 근거는 현황판 릴리스 기록에 확정한다. 기존 보안 후속 조치와 별개이며 이번 변경만으로 P0-10을 완료 처리하지 않는다.
- 전체 Jest 최초 실행은 101개 묶음·826검사 통과/8개 묶음·67검사 실패였다. 이번에 바꾼 링크 안내 명칭의 기대값 2개를 수정하여 해당 파일 9검사를 재통과했다. 나머지는 별도 DB 시험환경이 없는 통합검사 6개 묶음·62검사와 이전 운영 기준 커밋에서도 동일하게 재현된 소개 버튼 검사 3개다. 운영 비밀키를 시험환경 대신 넣어 실행하지 않았으며 전체 검사를 모두 통과했다고 보고하지 않는다.

배포 후 확인은 운영 기본정보의 중복 근무지 영역 제거, 연락 안내·저장 항목, 카드 아래 삭제 버튼, 로고 파일 제공, 네이버 검색 연결을 기준으로 한다. 비밀키·로그인 정보·회원 자료·선택 주소 원문은 현황판에 기록하지 않는다.
