# 다모아 분류·경력 입력·공개 지도 배포

2026-11-16 KST. 사용자가 미리보기 변경의 커밋·푸시·병합·운영 배포를 승인했다.

## 포함 변경

- 다모아 네 대분류 모아 보기·세부 분류 검색, 경력 전용 입력, 회사명 중복 제거.
- 선택 기관 정보·증빙, 다모아 및 각 프로필의 주소/지도 표시 선택.
- 프로필 관리 하위 메뉴 펼치기.
- 공개 주소의 실제 네이버 지도 표시, 본문 마지막 왼쪽 정사각형 배치, 기관명·주소 하단 배치. 불필요한 제목·안내·외부 지도 버튼 제거.
- 지도 오류 응답이 없을 때 예외 방지, 공개/편집 화면의 지도 요청 시점과 개인정보처리방침 일치.

## 검증

- 일반 회귀 67개 묶음 / 424개 항목 통과, TypeScript 및 변경 형식 검사 통과.
- 로컬 Supabase가 필요한 기존 통합 테스트 6개 묶음은 미실행. 신규 DB 변경은 없다.
- 실제 로컬 공개 화면에서 지도 타일·마커, 320×320 크기와 문구 제거 확인. 이전 사용자 입력·파일·게시 상태는 변경하지 않았다.
- 네이버 업체 검색·플레이스 선택, 모바일 실기기 검증은 이번 완료 범위에 포함하지 않는다. 기존 보안 후속 작업도 별개로 유지한다.

## 현황판

- 기능 변경·검증·배포 결과만 기록하며 키·토큰·회원 식별자·주소·파일 원문은 담지 않는다.
- 온라인 게시의 기존 인증 전달 차단이 남아 있으므로 로컬 기록과 온라인 반영 완료를 구분한다.
- 최종 PR·병합 커밋·운영 배포 결과는 후속 배포 기록으로 확인한다.
