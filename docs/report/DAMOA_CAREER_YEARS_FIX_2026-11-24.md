# 다모아 경력 연수 합산 누락 수정

후속 사용자 요청으로 검증된 앱 수정의 커밋·푸시·PR 병합·운영 배포를 진행한다. 아래 로컬 단계의 미배포 기록은 당시 상태이며 최종 운영 확인은 현황판에 이어 기록한다. DB·게시 자료·접근 권한은 변경하지 않는다.

## 원인

읽기 전용 공개 프로필 조회에서 다모아 경력 3개는 공개되어 있었으나 예전 경력 목록은 0개, 기존 총 경력 값은 비어 있었다. 프로필 버전 적용과 탐색 카드가 예전 목록의 총 연수만 사용해, 실제 화면에 표시되는 다모아 경력을 합산하지 않는 연결 누락이었다.

## 수정

- 공개 대상으로 걸러진 기존 경력과 다모아 ‘경력’ 기간을 같은 계산에 넣는다. 기존 기간 표기 정규화와 중복 기간 병합·현재 날짜·정수 연수 반올림 로직을 재사용한다.
- 공개 프로필, 탐색·홈의 대표 카드, 작성자 미리보기에 연결했다. 공개 전 확인에서 제외한 경력이 기존 합계로 남지 않도록 다시 계산한다.
- 항목 제외·기간 비공개는 계산 대상에서 제외한다. 원본 다모아의 비공개 날짜를 별도로 가져오지 않는다. 연도만 있는 기간, 단일 날짜, 잘못되거나 모호한 기간은 추정하지 않는다. 기존 경력의 확인된 총 연수는 재구성이 불가능한 경우 기존 기준으로 유지한다.
- 완전한 공개 날짜의 일 정밀도를 유지하도록 기존 계산 함수가 월 또는 일 형식 모두 받도록 호환 확장했다. 기존 월 단위 이력서 계산은 유지한다.

## 검증과 상태

- 관련 11개 묶음 61검사와 타입·공백 검사 통과. 세 경력 합산, 공개 제외·날짜 비공개, 잘못된 기간, 기존 경력과 중복, 재직 중, 일 정밀도, 목록 카드, 공개 전 확인 제외를 확인했다.
- 독립 검토에서 차단 사항은 없었다. 별도 넓은 범위의 기존 공개 전 확인 검사에는 이미 제거한 근무지 영역을 기대하는 실패가 남아 있어 전체 검사 완료로 표시하지 않는다.
- 실제 로컬 공개 프로필의 상단에 ‘경력 4년’이 표시되는 것을 확인했다. 저장 자료 변경·시험 게시·권한 변경·DB 변경·커밋·푸시·운영 배포·현황판 게시는 하지 않았다.
