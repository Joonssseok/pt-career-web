# 상세소개 공통 편집 도구

- 사용자 요청에 따라 상세소개에 게시글의 두 줄 도구 모음을 재사용했다. 글꼴·크기·색상·형광펜·양쪽 정렬·목록·인용·코드·표·링크·특수문자·찾기를 제공한다. 일반 소개 편집기는 유지한다.
- 기존 사진·GIF·동영상 파일·유튜브 삽입, 이미지 크기·자르기, 원본 보존을 유지한다. 상세소개 전용20MiB·파일당20MiB·첨부20개·글5000자·문서 크기 및 깊이 제한은 변경하지 않았다. 게시글의 용량 정책으로 바뀌지 않는다.
- 상세소개 전용 검증과 표시를 확장했다. 사진/영상은 기존 소유 파일 목록에서만 표시하며 표·인용 안에 첨부를 중첩해 소유 검사 경로를 우회할 수 없다. 임의 HTML/CSS·외부 이미지와 스크립트 링크는 허용하지 않는다.
- 같은 저장 범위의 순수 문서 검증 변경 `20261120114023_detail_editor_tools`를 운영 저장 구조에 적용했다. 검증 함수는 고정 검색 경로에서 입력 JSON만 검사하며 데이터 읽기·쓰기·동적 SQL이 없다. 기존 실행 권한과 저장·공개 함수/소유권·첨부 저장소 정책은 유지했다. 개인 자료 수정/삭제/게시를 하지 않았다.
- 화면·문서·미디어·기존 자동 저장 등6묶음124검사와 타입 검사를 통과했다. 이후 실제 Tiptap 표·글꼴·링크와 기존 GIF/동영상 혼합 문서의 검증·표시 검사도 추가해7개 도구 검사를 통과했다. 격리 PostgreSQL111검사와 기존 상세 미디어/소유권42검사를 통과했다. 운영의 가상 문서 검증 true, 방문자 함수 호출 차단·회원 허용·비공개 검증 보조 함수 직접 호출 차단을 확인했다. 보안 점검 변경 전후5개 항목으로 새 경고가 없다. 기존 보안 후속 작업은 남아 있다.
- 실제 로그인된 상세소개 단계에서 공통 도구와 기존 등록 사진을 확인했다. 사용자 문서에 시험 입력/저장/게시를 하지 않았다. 실파일을 이용한 운영 쓰기 검사는 수행하지 않았다.
- 앱 커밋·푸시·배포와 온라인 현황판 게시는 수행하지 않았다. 로컬 상세소개 미리보기에서 확인할 수 있다.
