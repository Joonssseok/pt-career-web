# 상세소개 저장 한도 20MB

- 사용자 요청으로 상세소개 사진·GIF·동영상 전용 합계 한도를 200MiB에서 20MiB로 변경했다. 다모아 50MiB와 유튜브 링크는 별도다.
- 파일당 20MiB와 최대 20개 기준을 유지한다. 화면/클라이언트의 합계 검증 및 안내를 20MB로 맞췄다.
- 운영 서버의 기존 예약·완료·업로드 허용 함수만 호환 변경했다. 예약은 계정의 남은 용량을 확보하고 완료 시 실제 크기로 줄인다. 작은 파일을 여러 개 순차 업로드할 수 있고 미완료 예약도 합계에 포함한다. 동시 요청은 기존 계정 잠금을 유지한다.
- 완료 검증에서 예약분 초과 및 계정 합계 20MiB 초과를 차단한다. 이미 완료된 파일은 새 한도와 관계없이 유지한다. 기존 자료 자동 삭제나 자동 게시가 없다.
- 변경 전후 상세소개 파일 행·원본 객체·첨부 연결·프로필 데이터 지문과 함수 실행 권한 동일 확인.
- 관련 테스트 79개, 독립 PostgreSQL 18검사와 TypeScript 검사 통과. 운영 검증용 업로드·수정·삭제는 수행하지 않았다.
- 후속 사용자 요청으로 커밋·푸시·병합·앱 배포 및 현황판 게시를 진행한다. 최종 커밋·배포 상태와 운영 확인 결과는 현황판 배포 기록에 남긴다.
- 복구: supabase/rollback/profile_detail_quota_20mb.sql은 이전 함수만 복원하며 원본 자료는 변경하지 않는다.
