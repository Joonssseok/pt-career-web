# 대표 프로필 실제 공개 전환 연결

- Status: 검증 완료, 운영 배포 결과는 개발 현황판에 기록
- Date: 2026-11-02 KST
- Authority: 사용자 '공개할 수 있게 바꿔' 요청 및 공개 전환·조회 함수의 운영 DB 변경 명시 승인

## 변경

공개 전환 차단을 해제해 '프로필 저장' 후 '공개프로필 업로드'를 누르면 본인 소유의 저장된 프로필이 대표 공개본이 된다. 대표 한 개와 기존 profiles.id 공유주소를 유지한다. 저장만으로는 공개본이 바뀌지 않는다. 기본 승인·공개 조건, 정지·삭제 요청 계정 제한 및 소유자 검증을 유지한다.

공개 전 제외한 항목을 안정적인 식별값으로 초안에 저장한다. 공개 함수는 제외 이력·소개·근무지·선택하지 않은 섹션을 걸러내고, 공개 조회는 현재의 비공개/취소 설정을 다시 확인한다. 제외한 기록의 내용이 담길 수 있는 정렬 메타데이터도 공개 응답에서 걸러낸다. 관리용 제목·소유자·미공개 초안·제외 식별값은 공개하지 않는다. 목록 카드의 경력·근무지도 실제 공개본에 맞춘다.

서버 JSONB의 속성 순서 변경을 미저장 수정으로 잘못 판단하던 비교를 수정해, 저장 후 업로드 버튼이 계속 비활성화되지 않도록 했다.

## 검증

- 타입 검사·운영 빌드 통과. 프로필/정렬/공개 카드 회귀 테스트 17개 통과.
- enable_profile_publishing 마이그레이션 운영 적용.
- 합성 데이터 검증: 제외 이력·소개·근무지·정렬 메타데이터에서 비공개 내용이 노출되지 않음. 형식 검증 및 익명 공개 실행 차단 확인.
- 롤백 트랜잭션 검증: 실제 소유자 문맥에서 임시 프로필 저장/공개, 대표 하나·고정 공유 ID·다른 소유자 공개 차단·관리 제목/제외 식별값 비노출 확인. 모든 임시 초안 및 프로필 변경 롤백. 기존 사용자의 공개본을 임의 교체하지 않음.
- 로그인 로컬 화면에서 기존 저장된 프로필의 업로드 버튼 활성화 확인. 브라우저에서 실제 사용자 공개본을 교체하는 버튼은 누르지 않음.

## 제한·롤백

새 증빙 첨부와 관리자 심사 요청 전송은 여전히 미리보기다. 인증파일 공개 동의용 별도 DB 변경은 적용하지 않았다. 이번 변경 자체로 초안 자동 공개나 첨부 원본 공개는 하지 않는다.
앱 롤백 시 LIVE_PROFILE_PUBLISH_ENABLED=false로 되돌리고 DB의 초안/공개 스냅샷은 보존한다.
