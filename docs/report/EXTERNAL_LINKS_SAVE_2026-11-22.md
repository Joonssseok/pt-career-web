# 외부 링크 작성·저장 연결

상태: 로컬 구현·저장 연결·실제 작성창 확인 완료. 2026-11-22 사용자 배포 요청에 따라 운영 반영 진행.

- 프로필 작성 1단계의 소셜·추가 링크를 외부 링크 편집기로 통합.
- 종류·표시 이름·URL과 정렬 순서 저장. 대표 설정 UI는 후속 요청에 따라 제거.
- 기존 소셜 5종과 추가 링크를 함께 불러오며 조회만으로 변환하지 않음.
- 유효한 저장에 성공할 때만 통합 목록으로 옮기고 기존 소셜 열을 비움.
- 공개 프로필의 전문분야 위에 모든 링크를 동등한 원색 로고·사용자 지정 문구로 표시. 링크 박스와 대표 강조는 제거.
- 빈 링크 영역은 표시하지 않음. 소개의 항목 추가·삭제 버튼 제거 유지.

## 데이터와 접근

`20261122091934_profile_external_links.sql`을 연결된 DB에 적용했다. 기존 링크 행과 소셜 값의 적용 전후 지문이 같음을 확인했다. 실제 사용자 링크를 추가·변경하지 않았다.

기존 링크 테이블에 종류·대표 여부만 추가한다. 소유자 인증·잠금·입력 검사 후 순서와 대표 여부를 함께 저장한다. 읽어온 원래 목록이 달라졌으면 저장을 거절한다. 링크 저장 실패 시 기본정보 저장도 시작하지 않아 오래된 소셜 값이 다시 들어가지 않게 했다. 미완성 입력과 불러오기 실패는 저장을 막고, 취소 시 자동 저장 재시도가 이어진다.

공개 대상·뷰의 기존 필터·RLS를 유지한다. 새 함수는 로그인한 본인 자료만 다루고 익명 실행은 차단한다. 구형 링크 저장기가 새 메타데이터를 지우지 못하도록 보호한다. 복구 파일은 새 함수 접근·표시만 회수하고 저장 자료는 남긴다.

보안 점검 분류는 전후 5종으로 동일했다. 로그인 사용자 호출이 의도된 소유자 전용 함수 2개가 기존 [SECURITY DEFINER 점검 경고](https://supabase.com/docs/guides/database/database-linter?lint=0029_authenticated_security_definer_function_executable)에 추가되었다. 본인 확인·비어 있는 search_path·실행 권한 제한을 코드와 격리 DB에서 확인했다. 기존 보안 후속 작업을 완료 처리하지 않는다.

## 검증과 제한

- 관련 화면·액션·부모 저장 테스트 25개 통과.
- 격리 PostgreSQL 테스트 119개 통과: 저장·재조회, 순서·대표, 다른 소유자·비공개·익명 접근, 잘못된 주소, 오래된 화면 충돌, 구형 저장·복구 시 자료 보존.
- TypeScript 검사 통과.
- 실제 DB의 함수 존재·익명 실행 차단·원본 보존 확인.
- 실제 계정의 시험용 링크 쓰기/ROLLBACK 검증은 자동 승인 검토에서 실제 사용자 자료 및 트리거 부작용 위험으로 거절되어 실행하지 않음. 이 경로로 우회 검증하지 않음.
- 후속 브라우저 확인 완료: `http://localhost:3000/my/profiles`에서 기존 계정으로 로그인하고 기본 프로필의 1단계 기본 정보 → 외부 링크를 펼쳐 실제 편집기에 새 양식이 표시되는 것을 확인했다. 기존 계정 자료를 읽었으며 링크 입력·변경·저장은 하지 않았다. 별도 디자인 미리보기 화면이 아니다.

## 로컬 작성창 표시

- 3002에서 로그인 후 운영 사이트로 돌아가던 경로 대신 3000에서 기존 Google 로그인으로 정상 진입했다. 인증 설정이나 허용 주소는 변경하지 않았다.
- 별도 개발 캐시는 `PTCAREER_DEV_DIST_DIR=.cache/external-links-next-3000`으로 지정한다. OneDrive 밖의 캐시 디렉터리를 연결하고, 실행 프로세스의 `NODE_PATH`는 프로젝트 `node_modules`로 지정했다. 기존 3002 서버는 유지한다.
- `next.config.mjs`의 캐시 위치 선택은 개발 모드에만 적용한다. 운영 모드에는 반영되지 않는 것을 검사했다. 개발 서버가 자동 추가한 임시 TypeScript 설정은 원래대로 복구했다.

## 후속 링크 양식 조정

- 대표 선택·대표 없음·위/아래 이동 버튼 제거. 모든 링크를 등록한 순서로 동일하게 표시한다.
- 수정 화면도 원색 로고를 사용하고 수정·삭제를 작은 버튼으로 줄였다. URL은 한 줄로 표시하고 넘치는 부분은 생략하며 전체 주소는 툴팁/수정 입력에서 확인한다.
- 이력에서 사용하는 기존 정렬 컴포넌트를 재사용해 왼쪽 손잡이로 마우스·터치 드래그 및 방향키 정렬을 지원한다. 링크 한 개는 손잡이를 비활성화한다.
- 기존 대표 메타데이터는 충돌 확인에 보존하고, 정상 저장할 때 모든 링크를 비대표로 보낸다. 공개 화면에서는 과거 대표 여부도 표시 순서나 크기에 영향을 주지 않는다. 추가 DB 변경이나 기존 링크 강제 변환은 하지 않았다.
- 실제 로컬 프로필 작성창 및 공개 프로필에서 원색 로고, 편집 버튼 크기, URL 한 줄 표시, 대표 컨트롤 제거, 전문분야 위 배치 확인. 새 시험용 링크를 실제 계정에 저장하지 않았다.
- 관련 테스트 36개 및 TypeScript 검사 통과. 앱 배포 없음.

초기 구현 요청에는 현황판 온라인 게시와 앱 배포가 포함되지 않았으며, 이후 사용자가 앱 배포·반영을 요청했다.
