## 변경

공통 타이포그래피 토큰과 기본 본문, 홈 화면의 별도 CSS 글자 크기에 각각 1pt(96dpi 기준 약 1.3333px)를 더했다. 고정 크기의 다모아/프로필 라벨 및 프로필 제목 입력도 공통 토큰으로 전환해 같은 증가 폭을 적용했다. 기존 root rem 기준을 유지하므로 컨테이너·여백·버튼 크기를 전체 확대하지 않는다. 데이터와 공개 정책은 변경하지 않는다.

## 검증

- TypeScript 및 diff 검사 통과.
- 격리된 검증 폴더에서 Next.js 운영 빌드 통과.
- 로컬 홈 실제 계산값: 제목 60→61.3333px, 소제목 40→41.3333px, 검색 입력 15→16.3333px. 전문가 탐색 제목 37.3333px 및 작은 버튼 16.3333px 확인.
- 로컬 홈 390×844 모바일 화면 확인, 가로 넘침 없음(뷰포트 390px / 문서 폭 375px). 임시 화면 크기 설정 복원.
- 폰트 서식 변경으로 추가 단위 테스트는 작성하지 않았다. 모든 로그인 화면과 실기기 전체 흐름을 별도로 재검증한 것은 아니다.
