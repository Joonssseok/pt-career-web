# 프로필 입력창 디자인 비교 (2026-11-24)

후속 사용자 선택: B ‘밑줄만’. 실제 프로필 작성 기본정보의 이름·프로필 제목·한 줄 소개·지역 선택·연락처·주소·네이버 검색 입력에 적용했다. 박스 배경·둥근 테두리 대신 밑줄로 구분하고 포커스 시 밑줄을 강조한다. 글자 크기와 입력/공개·저장 동작은 유지한다. 체크박스·파일 선택·다른 단계의 편집기는 제외하며 앱 배포는 하지 않았다. 아래는 선택 전 비교 화면 제작 기록이다.

적용 확인: 실제 로그인된 프로필 수정 화면에서 대상 입력/선택 11개의 상단 테두리 0·하단 테두리 1px·모서리 0을 확인했다. 포커스 선 색상과 기본 폭/375px의 가로 넘침 없음을 확인했다. 입력 내용·공개 체크를 변경하거나 저장·게시하지 않았다. CSS 변경이므로 새 자동 검사는 추가하지 않았다.

사용자 요청에 따라 기존 항목명·입력칸·공개 체크의 가로 배치를 유지하면서 네 가지 디자인을 개발 환경에서 비교하도록 만들었다.

- A 얇은 테두리: 작은 모서리, 흰 배경, 얇은 윤곽. 기존 화면과 자연스럽게 이어지는 기본 추천안.
- B 밑줄만: 박스 없이 입력 아래 선으로 구분.
- C 묶음 행: 설정 목록처럼 여러 입력을 한 그룹에 배치.
- D 은은한 배경: 옅은 배경으로 입력 영역을 구분.

위치: `http://localhost:3000/preview/input-styles`.

전체 비교·개별 확대·휴대폰 폭 전환과 입력/포커스 상태를 제공한다. 같은 비교용 입력값을 각 시안에 공유한다. 실제 연락처 조회·프로필 저장·공개 설정 변경·외부 서비스 전송은 하지 않는다. 기존 실제 작성창은 변경하지 않았다. 선택한 안의 실제 적용과 앱 배포는 아직 하지 않았다.

타입 검사 통과. 브라우저에서 전체/개별 전환과 비교 입력 동기화를 확인했고, 실제 폭 375px에서 네 시안의 가로 넘침 없음과 입력 폭을 확인했다. 확대 상태를 포함한 입력 포커스 스타일은 시안 CSS에서 제공한다. 비교 화면은 개발 환경에서만 열리며 운영 환경에서는 404 처리한다.
