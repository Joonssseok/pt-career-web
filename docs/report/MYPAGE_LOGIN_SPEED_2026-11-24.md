# 마이페이지·로그인 속도 개선 — 로컬, 미배포

2026-11-24. 사용자 요청으로 속도를 개선하고 수정 전후를 비교했다. 운영 앱 배포·푸시·DB 변경·새 권한 부여·온라인 현황판 게시는 하지 않았다.

## 변경

- 서버 렌더 요청 한 번 안에서만 로그인 사용자·본인 프로필·버전 메타데이터를 재사용한다. React `cache`를 사용하며 계정 간/요청 간 영구 캐시를 만들지 않는다. 기존 사용자 검증과 소유자 필터를 유지한다.
- 마이페이지에서 메뉴와 본문을 함께 준비한다. 여섯 조회 뒤 전체 대표 프로필 RPC와 게시 여부 조회를 기다리던 두 번째 단계를 없앴다. 버전 조회에 게시 시각·게시 이름·게시 한 줄 소개의 작은 JSON 필드만 포함한다. 목록은 최근 3개, 전체 건수는 정확한 count, 메뉴의 생성 순서는 유지한다.
- 마이페이지·로그인 경로에 로딩 상태를 추가하고 마이페이지 메뉴·본문을 각각 스트리밍한다. 로딩 상태에는 회원 정보를 넣지 않는다.
- 로그인 후 PIN 준비의 검증·RPC·세션별 HttpOnly 표식을 유지하고, 쿠키 변경에 이미 동반되는 갱신 외의 루트 재검증과 이동 직후 refresh를 제거한다. PIN 설정 완료·재설정의 기존 갱신은 유지한다.
- QR코드 라이브러리 로딩과 PNG 생성은 QR 버튼을 처음 눌렀을 때 시작한다. 생성 실패 재시도와 프로필 변경 시 이전 QR 무효화는 유지한다.
- `vercel.json`에 DB와 같은 시드니 `syd1` 실행 지역을 준비했다. 운영 지역을 바꾸거나 배포하지 않았으므로 아래 수치에 이 효과는 포함되지 않는다.

## 실측

동일한 실행 중인 로컬 Next 개발 서버, 같은 로그인 세션, 같은 `/my` 전체 HTML 요청, 같은 원격 DB를 사용했다. 각 단계의 첫 요청 1회는 컴파일/예열용으로 제외하고 5회 순차 측정했다. 수정 전/후를 별도 시간대에 측정했으므로 네트워크 변동은 남는다. 운영 사이트의 앞선 브라우저 자동화 소요 시간과 직접 비교하지 않는다.

임시 루프백 측정기가 브라우저 쿠키를 메모리에서만 해당 로컬 서버로 전달하고 HTML의 고정 표식 도착 시각을 기록했다. 쿠키·응답 HTML·회원 자료는 저장하거나 출력하지 않았다. 저장한 결과는 시간 숫자뿐이다.

| 항목 (중앙값) | 수정 전 | 수정 후 | 단축 |
| --- | ---: | ---: | ---: |
| 서버 첫 응답 | 1,247ms | 402ms | 67.8% |
| 메뉴 HTML 준비 | 1,249ms | 464ms | 62.9% |
| 본문 HTML 준비 | 1,249ms | 723ms | 42.1% |
| 응답 수신 완료 | 1,260ms | 723ms | 42.6% |

- 본문 준비 5회: 전 `[1249,1265,1000,1192,1494]`ms, 후 `[979,706,723,715,770]`ms.
- 첫 응답 5회: 전 `[1247,1263,998,1190,1492]`ms, 후 `[944,389,401,462,402]`ms.
- 이는 서버에서 HTML이 준비되는 시간이며 브라우저의 그림 그리기·전체 JS 실행·이미지 다운로드 완료 시간은 아니다.
- 실제 계정의 비밀번호 로그인을 다시 수행하지 않았으므로 로그인 전체 소요 시간과 지역 변경 효과는 수치로 주장하지 않는다. 관련 자동 검사와 기존 로그인 상태의 실제 화면으로 확인한다.

## 검증

- 관련 10개 테스트 묶음의 100검사 통과: 마이페이지 데이터/표시, 계정 설정 배치, 공유 도구, 로그인 흐름, PIN 액션/표식/UI, OAuth 콜백, 네이버 로그인. 타입 검사와 diff 공백 검사 통과.
- 독립 검토에서 출시 차단 결함이 발견되지 않았다. 실제 로컬 브라우저에서 로그인된 헤더·프로필/활동/자료 건수·공개/비공개 프로필 상태가 유지되고, 버튼 클릭 시 QR이 생성되는 것을 확인했다.
- 전체 저장소 테스트와 운영 배포, 실제 계정의 새 비밀번호/소셜 로그인, 운영 지역 변경 성능은 이번에 검증하지 않았다. 임시 측정 서버는 종료했다.

기존 계정·자료·공개 설정·PIN 접근 정책은 변경하지 않는다. P0-10의 기존 후속 보안 확인은 이번 작업으로 완료 처리하지 않는다.

## 릴리스 승인

후속 요청으로 위 검증된 범위의 커밋·푸시·병합·운영 배포를 진행한다. 시드니 실행 지역 설정을 포함하며, DB 이동·자료 변경·새 공개 권한은 포함하지 않는다. 배포 결과와 운영 확인은 별도로 기록한다. 앞선 로컬 실측과 실제 운영 사이트의 성능 수치를 혼동하지 않는다.
