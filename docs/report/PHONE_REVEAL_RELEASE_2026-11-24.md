# 연락 전화번호 펼쳐 보기 릴리스 · 2026-11-24

사용자가 전화번호 펼침과 이력 안내 제거의 커밋·푸시·PR 병합·운영 배포, 개인정보 없는 현황판 기록을 승인했다.

- 연락·문의 카드의 공개 전화번호는 처음에는 전화 아이콘과 ‘전화연결’로 표시한다. 첫 클릭은 번호를 펼치며 전화를 걸지 않는다. 펼친 번호의 링크를 누르면 기기의 통화 연결을 요청한다. 다시 누르면 접는다.
- 작성자 카드도 같은 화면 부품을 사용한다. 번호 변경·공개 항목 제거 후에는 펼침 상태를 초기화한다. 공개하지 않은 번호와 빈 번호는 표시하지 않는다.
- 홈 전체 이력과 이력 탭 아래의 인증 설명 문구와 사용하지 않는 스타일을 제거한다. 항목별 인증 표식·공개 증빙·검색·날짜·이력 순서는 유지한다.
- 이 변경은 화면 표시를 접는 기능이다. 안심번호 발급이나 서버 공개 응답에서 번호를 제거하는 기능은 아니다. 기존 저장·게시·공개 설정·접근 권한은 변경하지 않는다.

## 검증과 범위

- 관련 6개 묶음 40검사와 타입·공백 검사 통과. 번호 펼침·접힘·유효한 통화 링크·번호 변경과 공개 제거 시 초기화·기존 연락처 공개 경계를 포함한다.
- 로컬 실제 프로필에서 첫 화면 전화 링크 0개, 클릭 후 번호 링크 1개, 다시 접은 후 0개와 인증 안내 제거를 확인했다. 실제 전화 연결·시험 저장·게시·자료 삭제는 수행하지 않았다.
- 이번 배포에 DB 전환·새 권한·전화 서비스 계약·안심번호 비용 발생은 없다. 최종 운영 배포 식별자와 확인 결과는 현황판에서 기록한다.
- 기존 전체 검사 중 별도 시험 DB가 필요한 검사와 이전 소개 버튼 기준의 검사 실패, 기존 보안 후속 P0-10은 이번 작업으로 완료 처리하지 않는다.
