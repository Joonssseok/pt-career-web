# 프로필 카드의 병원 근무 설명·근무지 표시 (2026-11-24)

- 공개 프로필 카드와 작성자 카드의 긴 병원 근무 문단을 제거했다. ‘병원 근무’ 표시에 커서를 올리거나 키보드/터치로 초점을 주면 ‘현재 병원에서 일하고 있어요.’를 표시한다. Escape로 설명을 닫을 수 있다. 홈의 분류 안내와 탐색 카드의 기존 안내는 이번 변경 대상이 아니다.
- 주소 공개 시 선택한 업체명을 위에 14px, 주소·상세주소를 아래에 12px로 표시한다. 업체명이 없는 주소 검색 결과는 기존처럼 주소만 표시한다.
- 클라이언트와 서버의 공개 주소 결과에 선택적 `address.name`을 연결했다. 주소 비공개·지도만 공개인 경우 이름을 전달하지 않는다. 지도 결과는 위도·경도만 유지하며 비공개 입력 전체를 공개 컴포넌트에 넘기지 않는다.
- 공용 DB에서 기존 순수 표시 함수 `profile_contact_inquiry_public(jsonb)` 하나만 교체했다. 테이블·저장 자료·권한·인증·저장/게시 동작은 변경하지 않았다. 적용 전후 프로필과 버전 자료의 비교값, 함수 권한이 일치함을 확인했다. 기존 게시된 공개 주소에도 업체명이 함께 전달되며 앱 화면은 아직 배포하지 않았다.
- 준비 파일: `supabase/migrations/20261124015432_profile_contact_location_name.sql`. 실제 DB 적용 이력: `20261124015753 / profile_contact_location_name`. 후속 릴리스에서 이력을 대조해 중복 적용을 피한다. 복구 파일: `supabase/rollback/profile_contact_location_name.sql`.
- 관련 자동 검사 19개·타입 검사·독립 PostgreSQL 276개 검사 통과. 운영 DB의 가짜 값 조회에서 주소/지도 공개 조합 4가지의 이름·주소·지도 제한을 확인했다. 실제 회원 자료를 검증용으로 변경하지 않았다.
- 브라우저에서 실제 이름 위/주소 아래 배치와 글자 크기, 설명 표시·Escape 닫기를 확인했다. 375px에서도 가로 넘침이 없고 설명이 화면 안에 표시된다.
