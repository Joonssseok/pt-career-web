# 프로필 삭제·클릭 가능한 미리보기

2026-11-08 · 사용자 승인 릴리스 · 실제 커밋/병합/배포 상태는 PR 기록으로 구분

- 작성 작업의 하단에 프로필 삭제를 배치했다. 확인창에서 제목과 복구 불가·관련 심사 내역 삭제·원본 보존을 안내한다. 취소는 입력을 유지하고 실패는 확인창 안에 표시한다. 새로 작성 중인 미저장 프로필에는 삭제 버튼을 두지 않는다.
- 현재 대표 프로필은 화면과 서버 양쪽에서 삭제를 차단한다. 다른 프로필을 먼저 게시해 대표를 변경한 후 삭제하도록 안내한다. 미리보기용 예시 화면은 실제 삭제를 호출하지 않는다.
- 공개 전 확인 상단의 미리보기는 별도의 큰 창을 연다. 현재 편집 내용·표시 선택·순서·이미지를 공개 화면과 같은 컴포넌트로 렌더링하고 편집 손잡이·+/−·게시/심사 버튼·관리용 제목은 숨긴다. 링크·갤러리·허용된 증빙은 기존 기능을 사용한다.
- 미리보기 공유 버튼은 게시 전 안내만 표시한다. 실제 공유·복사·게시·저장·심사 요청은 실행하지 않는다. 증빙이 바뀌거나 공개 선택이 달라지면 기존 승인을 미리보기에 자동 승계하지 않는다. 요약 건수는 공개 전 확인과 같은 기준을 유지한다.

## 서버 범위와 검증

- 사용자에게 본인 비대표 프로필 삭제 범위를 설명하고 명시적 서버 변경 승인을 받은 뒤 `delete_own_profile_version`을 적용했다. 직접 테이블 DELETE 권한을 부여하지 않고 함수 내부에서 로그인·본인 소유·같은 기본 프로필 소속·대표 여부를 검증한다.
- 대표 게시와 같은 기본 프로필→버전 순서로 잠금을 잡아 대표 전환과 삭제의 경쟁을 막는다. 다모아 원본·공통 정보·저장된 원본 파일·타 프로필·공개 설정·고정 공유주소는 변경하지 않는다.
- 실제 적용된 마이그레이션 버전은 20261108142613이다. 복구 시 함수 실행 권한을 회수하거나 함수를 제거하면 된다. 사용자가 확인해 삭제한 초안 복구는 별도 백업이 필요하다.
- TypeScript 통과. 삭제 확인/취소/실패/성공, 대표 보호, 비로그인 차단, 미리보기 비전송·외부 링크·증빙 승인 유지, 기존 첨부/게시 흐름을 포함한 관련 검사 5개 묶음·34개 항목 통과.
- 서버에서는 새 검증용 버전 1개만 트랜잭션 안에서 생성했다. 다른 소유자의 삭제 차단·본인 삭제 성공·익명 실행 불가·직접 DELETE 권한 미부여·기존 프로필 수 보존을 확인하고 전체 롤백했다. 실제 회원 프로필은 삭제하지 않았다. 대표 삭제 차단은 코드/모의 검사로 확인했으며 운영 대표 프로필을 대상으로 삭제를 시도하지 않았다.
- 보안 점검은 적용 전후 기존 5개 항목으로 같고 신규 항목은 없었다. 기존 보안 후속 작업은 완료 처리하지 않는다.
- 브라우저에서 실제 계정의 삭제 확인창을 열고 취소했다. PC/모바일 미리보기 창·공유 안내·닫기/Escape 복귀를 확인했다. 실제 파일 원본 다운로드나 외부 메시지 전송은 수행하지 않았다.

## 함께 배포하는 화면 정리

- 마이페이지 우측 사용자 박스의 상태·제목·소개·공개 토글·공개 프로필 보기 버튼을 제거하고 세로형 사진을 크게 표시한다. 이름과 내정보 수정은 유지한다. 기존 공개 상태는 변경하지 않는다.
- 공개 전 확인에서 단일 항목에도 동일한 내부 들여쓰기를 적용한다. 학력·경력·교육의 본문 시작 위치가 같으며 단일 항목에는 이동 손잡이를 표시하지 않는다. 읽기 전용 미리보기와 실제 공개 화면에는 편집용 여백을 추가하지 않는다.
- 배포 전 TypeScript 통과. 운영 DB 쓰기가 없는 자동 검사 57개 묶음·362개 항목 통과. 별도 테스트 DB 설정이 필요한 기존 통합 검사 6개 묶음은 설정 부재로 실행 불가였으며 운영 키를 주입하지 않았다.
- 서버 마이그레이션 적용 기록, 익명 실행 차단, 인증 계정 함수 실행 허용, 직접 테이블 삭제 권한 미부여를 읽기로 재확인했다. 새 DB 변경은 수행하지 않는다.
- 현황판에는 기능·검증 결과·PR/배포 상태만 기록한다. 접근 자격이나 회원 자료는 포함하지 않으며, 온라인 현황판 갱신 경로가 차단된 경우 로컬 기록과 구분해 표시한다.
