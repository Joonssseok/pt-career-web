# 공개 프로필 문서형 배치·항목 인증 표시

사용자 승인 릴리스 범위 · 2026-11-08

- 상단 사진·이름과 고정 요약을 유지하고 본문 카드의 테두리·상하 여백을 줄였다. 분류 제목은 작은 회색 글씨와 구분선으로, 실제 이력 이름은 더 크고 진하게 표시한다. 공개 화면과 공개 전 확인에 같은 본문 기준을 적용한다.
- 별도의 인증 내역 모음을 제거하고 해당 이력 옆에 파란 확인 표시를 제공한다. 공개가 허용된 증빙은 같은 항목에서 기존 워터마크 사본 경로로 연결한다. 비공개 파일은 링크를 만들지 않는다.
- 요약의 자격/면허 건수를 인증 경력으로 바꾸고 현재 공개 중인 관리자 점검 통과 항목만 센다. 조회 실패는 확인 필요로 표시하며 다른 비대표 초안은 현재 공개본의 수를 가져오지 않는다.
- 공개 프로필 사진·이름 박스 오른쪽 아래에 흰 배경·사각 테두리의 별표와 공유 버튼을 배치하고 본문 맨 아래 공유 버튼은 제거한다. 모바일에서는 버튼을 소개 문구 아래에 배치한다. 별표는 준비 안내만 열며 공유는 기존 기기 공유와 링크 복사를 유지한다.
- 원본 이력·저장 순서·공개 선택·서류 심사 조건은 유지한다. 새 공개 표시 조회 함수는 기존 공개 적격 함수의 결과를 재사용하고 원본 항목 키 대신 지문만 반환한다. 이미 적용된 조회 함수의 마이그레이션을 소스에 포함하며 이번 배포에서 다시 실행하지 않는다.

## 검증

- TypeScript 검사 통과.
- 운영 DB에 쓰지 않는 자동 검사 56개 묶음 / 353개 항목 통과. 항목별 인증·건수·표시 설정·순서 저장·공개/비공개 경계·워터마크 경로·공유 성공/취소·별표 안내를 포함한다.
- 별도 테스트 DB가 필요한 기존 통합 검사 6개 묶음은 테스트 자격 설정 부재로 실행하지 않았다. 운영 키를 주입하거나 회원 자료를 생성·삭제하지 않았다.
- 익명 역할의 서버 읽기 확인에서 현재 공개된 점검 통과 항목 12개, 중복 없는 항목 지문, 공개 파일 0개를 확인했다. 비공개 파일이나 원본 항목 키를 조회 결과에 추가하지 않았다.
- 로컬 PC와 모바일에서 문서형 본문·오른쪽 아래 버튼·모바일 문구 비겹침과 별표 준비 안내를 확인했다. 실제 공유 메시지는 전송하지 않았으며 공유 기능은 모의 검사로 검증했다.
- 운영 빌드·배포 및 운영 화면 확인은 PR·Vercel 배포·현황판에서 별도로 기록한다. 보안 후속 작업을 이번 UI 배포만으로 완료 처리하지 않는다. 비밀값·인증정보·개인 자료는 보고서와 현황판에 포함하지 않는다.
