## 완료한 코드
- 작성 화면 하단 저장/공개 버튼을 제거하고 우측 저장/공개 전 확인 작업창 추가. 저장 전 이동은 확인 팝업으로 안내. 공통 정보·직군·전문분야·링크 변경도 감지.
- 임베디드 프로필 이미지 교체는 새 경로를 사용하여 저장 전에 기존 공개 이미지 바이트를 덮어쓰지 않음.
- 다모아의 비공개 불변 파일 업로드와 100MB 저장량 정책 재사용. 항목별 첨부 저장과 관리자 심사 요청을 분리. 기존 자격 증빙은 비공개 파일을 복사하여 불변 자료로 보관.
- 관리자 승인/반려, 반려 사유, 동시 수정 충돌 방지. 첨부 변경 시 인증 초기화. 승인과 작성자의 파일 공개 선택 및 현재 대표 프로필 항목 일치 조건을 모두 만족할 때만 공개 조회/파일 열람.
- 첨부 중인 파일은 미사용 파일 정리로 지워지지 않도록 보호.

## 검증
- 타입 검사, 관련 테스트 28개, 별도 경로의 운영용 빌드 통과.
- 로그인 로컬 브라우저에서 우측 버튼 및 미저장 이동 확인 팝업 확인. 확인용 입력은 복원했으며 서버 저장/공개 클릭은 하지 않음.
- 운영 DB 권한 회귀 검증 SQL 통과. authenticated 실제 역할과 비회원 역할에서 요청·승인·공개 조건, 타인 요청/비관리자 승인 거절, 비공개 파일·제외 항목 비노출, 정리 삭제 방지를 검증. 모든 검증 자료·공개 변경은 트랜잭션 ROLLBACK으로 복원.

## 운영 DB 승인·적용 완료
- 자동 승인 검토가 profile_item_evidence_review 운영 마이그레이션을 거절: 새 테이블·파일 접근 규칙·공개 조회·삭제 보호 트리거에 대한 구체적인 명시적 승인 부족.
- 사용자 명시 응답: 이 범위의 운영 DB 변경 승인. 이후 profile_item_evidence_review 적용 성공. 승인 전 우회 실행하지 않음.
- 첨부 저장·심사 요청/승인·조건부 공개 서버 함수 연결과 SQL 검증 완료. 로그인한 로컬 브라우저에서 서버 심사 내역 로딩·첨부 팝업·기본 비공개 선택 확인. 기존 프로필에 실제 파일 제출/승인/공개 실험은 하지 않음. 웹앱 커밋·병합·운영 배포는 사용자 후속 요청으로 진행. 완료 증거는 현황판에 기록.
- 기존 license_evidence_public_choice 마이그레이션은 별도로 적용하지 않음. 이번 항목별 증빙 경로로만 연결.

- 승인 범위의 정리 호환 보완: profile_review_account_cleanup 적용. 심사 관리자 계정 삭제 시 reviewed_by는 NULL 처리하고, 사용자 계정 CASCADE 삭제를 첨부 보호 트리거가 차단하지 않게 함. 기존 유효 계정의 첨부 보호는 유지. 보완 후 운영 권한 SQL 재검증 통과. 검증 후 심사 기록 0건으로 확인.

## 다모아 자료 선택·미리보기 보완 (2026-11-08 · 승인 배포 대상)
- 증빙자료 첨부 창에서 현재 항목의 기존 파일과 본인 다모아 보관 자료를 함께 표시한다. 이 프로필에 불러오지 않은 활동의 자료도 선택할 수 있으며 다른 소유자의 활동·서버에 저장되지 않은 자료는 보관 목록에서 제외한다. 파일 ID로 중복을 제거하고 파일명·활동 이름·저장 크기를 표시한다.
- 기존 팝업 폭을 유지하고 파일 선택, 보관 자료 목록, 선택한 자료의 미리보기 순서로 세로 배치한다. 체크한 자료는 목록 바로 아래에 표시하며 ‘보기’로 첨부 선택 없이도 확인할 수 있다. 기존 기기 파일 추가도 유지한다.
- 현재 보는 파일 하나만 기존 인증 API로 읽어 JPG·PNG·WebP 또는 PDF를 표시한다. 요청 실패·지원하지 않는 형식은 안내와 원본 열기를 제공하고 실패한 미리보기는 다시 요청할 수 있다. 파일을 바꾸거나 창이 닫히면 요청을 취소하고 미리보기 Blob URL을 정리한다.
- 선택한 기존 다모아 파일은 재업로드하지 않고 기존 파일 ID로 연결한다. 기본 비공개, 명시적 첨부 저장/심사 요청, 관리자 승인 및 작성자 공개 선택 조건을 유지한다. DB·저장소 접근 권한 변경은 없으며 실제 회원 자료를 제출·공개하거나 심사 요청해 검증하지 않았다.
- 전체 49개 묶음/307개 자동 테스트와 TypeScript·diff 검사를 통과했다. 본인 보관 자료 표시·타인/미저장 자료 제외·기본 비공개 저장·이미지/PDF 미리보기·오류 재시도·오래된 응답 무시·Blob URL 정리를 검증했다. 기존 별도 DB·인증 환경 전용 테스트 제외 범위를 유지한다.
- 배포 전 실제 파일의 브라우저 표시는 미확인이었다. 사용자가 미리보기 로그인을 시도한 뒤 운영 사이트로 이동했고, 새 로컬 보호 화면도 로그인 화면으로 돌아가 미리보기 로그인 세션이 없음을 확인했다. 인증 설정이나 로그인 이동 허용 목록은 변경하지 않았다. 이 코드는 2026-11-08 사용자 승인 배포에 포함하고 운영 검증 결과는 현황판에 기록한다.
