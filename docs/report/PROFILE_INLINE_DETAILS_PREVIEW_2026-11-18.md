# 기존 프로필 항목 세부정보 가로 배치

- 소개·학력·경력·자격·교육 등의 기존 카테고리 제목과 밑줄, 순서, 글자 크기·색은 유지한다.
- 공통 경력·학력·자격·교육과 다모아 활동의 항목 사이 구분선을 제거한다. 직무·발급기관·주관·기존 공개 날짜는 항목명 옆으로 배치하고 좁은 화면에서 줄바꿈한다.
- 기존 인증 표시·증빙 열람·편집 동작·공개 선택 로직은 유지한다. 공통 조회 컴포넌트를 쓰는 공개 화면과 공개 전 확인에 같은 표시를 적용한다.
- TypeScript 및 관련 표시·순서·공개 설정 22개 테스트 통과. 실제 브라우저에서 발급기관이 항목 오른쪽에 같은 줄로 표시됨을 확인했다.
- 로컬 미리보기만 반영. 커밋·배포·DB 변경 없음. 배치 편집 프로그램과 저장값은 유지한다.

## 추가 조정 및 사진 표시 수정

- 항목명은 요청에 따라 기존 굵기(600)와 진한 글자색으로 복원했다. 세부정보의 작은 크기·우측 배치와 항목 사이 구분선 제거는 유지했다.
- 마이페이지는 현재 사진을, 공개 상세 화면은 게시 시 저장된 이전 사진을 참조하는 불일치를 확인했다. 공개 조회로 허용된 최신 사진 경로만 반영하고, 게시된 이력과 공개 선택은 그대로 유지하도록 수정했다. 사진을 제거한 경우에도 과거 사진을 복원하지 않는다.
- 관련 11개 테스트와 TypeScript 검사 통과. 실제 로컬 브라우저에서 마이페이지와 프로필의 사진 원본 일치, 이미지 로드 완료, 항목명 굵기 600을 확인했다.
- 로컬만 수정했으며 운영 사이트에는 아직 배포하지 않았다. 계정·사진·이력 데이터 변경 없음.
