# 활동 지역 선택과 프로필 조회 상단 고정

2026-11-08 KST. 미리보기 확인 후 사용자가 웹사이트 커밋·푸시·병합·배포를 승인한 릴리스 대상이다. 배포 완료 여부는 PR·운영 배포 상태와 현황판 기록으로 별도 확인한다.

## 조사와 변경
- 기존 지역 선택은 `WorkplaceSection`의 근무지 입력에 있었지만 현재 `commonOnly` 편집 경로에서 숨겨져 있었다. 공개 지역은 근무지의 소유자 표시·위치 공개 조건에 묶여 있었다.
- 현재 `/my/profiles` 기본정보에 주요 활동 지역을 추가했다. 기존 `REGIONS`의 17개 시·도를 재사용한다. 새 필드는 `VersionContent.activityRegion`이며 각 프로필의 일반 저장/게시 흐름으로 처리한다.
- 새 지역을 지정하면 선택한 시·도만 공개 요약과 지역 검색에 사용한다. 빈 문자열은 해제, 필드 자체가 없는 기존 프로필은 종전 동작이다. 기존 근무지의 주소·연락처를 공개하기 위해 위치 공개 설정을 켜는 방식은 사용하지 않았다.
- `/experts/[id]`만 사진·이름·직군·소개 한 줄 및 요약 수치를 96px 헤더 아래에 고정한다. 편집 미리보기와 순서 조정은 기존 동작을 유지한다. 커버·연락 링크·세부 이력은 일반 스크롤이며 고정 영역은 상세 본문 끝에서 멈춘다.
- 짧은 화면과 모바일에서는 사진·여백·요약 높이를 줄였다. 스크롤 이벤트 처리나 새 패키지는 추가하지 않았다.

## 서버와 검증
- 운영 마이그레이션: `20261108085627_profile_activity_region.sql`. 기존 함수 4개의 호환 가능한 보완이며 테이블·행·소유자 권한·인증 규칙·근무지 공개 설정 변경은 없다.
- 적용 직전 서버 함수 정의가 조사 시점과 동일한지 비교했다. 기존 공개 승인·정지·탈퇴·표시 제외 조건을 유지한다.
- `tests/profile-activity-region-permissions.sql`: 정상/잘못된 지역, 기존 형식 호환, 초안 저장 시 공개본 불변, 게시 후 조회/지역 필터, 재저장 시 공개본 불변, 재게시, 지역 해제, 비로그인 조회를 실제 서버에서 검증했다. 전체 트랜잭션을 롤백했고 검증용 프로필 잔존 수 0을 확인했다. 실제 회원의 선택을 저장하거나 게시한 상태로 남기지 않았다.
- `tsc --noEmit --incremental false` 통과. 기존 DB·인증 전용 검사군을 제외한 앱 자동 검사 51개 묶음/322개 테스트 통과. 회귀 검사는 지역 선택이 일반 저장 요청에 포함되고, 기존 근무지 숨김과 독립적으로 동작하는지 포함한다.
- 보안 Advisor의 기존 항목 이름·수준·건수가 적용 전후 동일하다. 새 경고는 없지만 기존 인증/함수 점검 과제 및 P0-10의 완료를 의미하지 않는다.
- 브라우저: 실제 로컬 공개 프로필은 상세 본문이 스크롤되어도 요약 상단 96px 유지. 390×844에서는 가로 넘침 없이 고정 영역 약 202px 확인. 개발용 예시 화면에서 경기 선택→저장→공개 전 확인의 지역 반영 확인. 예시 저장은 서버 쓰기를 하지 않으며 실제 저장/게시 연동은 위 롤백 SQL 검증으로 구분했다.

## 적용 상태와 복구
- 서버의 선택값 지원은 적용 완료이며 기존 데이터는 자동 변경하지 않는다. 웹사이트는 검증한 소스를 커밋해 기본 브랜치 병합 후 운영 배포하는 방식으로 반영한다.
- 이전 UI로 돌아가도 새 선택값을 삭제하지 않는다. 저장된 `activityRegion`이 있는 상태에서는 허용 형식을 축소하지 않고 호환 가능한 서버 검증기를 유지한다. 공개 여부는 작성자의 기존 게시 조작으로만 변경된다.
- 비밀값·인증 토큰·비공개 서류·회원 식별값은 이 문서에 포함하지 않았다.
