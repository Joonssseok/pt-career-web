사용자 확정: 직군 1~5개, 전문분야 1~3개 필수 유지. 0개 저장 허용은 진행하지 않음.

수정: 두 항목 모두 저장 전 검증·필수 선택 팝업·빨간 선택 수 표시. 선택 시 파란색 복귀. 필수 항목 누락 시 다른 섹션을 포함한 저장 차단. 로딩 실패도 저장 차단.
