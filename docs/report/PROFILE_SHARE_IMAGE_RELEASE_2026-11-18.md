# 프로필 링크 공유 이미지

- 사용자 승인 형식: 1200×630px, 연한 배경, 왼쪽 사진 전체와 여백, 오른쪽 이름/대표 직군. 현재 사이트와 같은 Pretendard 글꼴을 로컬에서 사용하고 공식 배포본의 사용 허가문을 포함한다.
- 공개 프로필의 Open Graph 및 Twitter 공유 이미지를 동적 이미지 경로로 연결했다. 표시 이름·대표 직군은 게시된 프로필 기준, 사진은 현재 공개 사진 기준이다. 사진이 없거나 읽을 수 없으면 이름 중심 카드로 표시한다.
- 사진 경로·이름·대표 직군을 반영한 이미지 주소 식별값으로 변경을 구분한다. 기존 편집 화면의 사진 교체도 매번 새 파일 경로를 사용해 같은 경로 덮어쓰기로 예전 공유 이미지가 남는 경우를 줄인다.
- 이미지 생성은 요청자의 쿠키/Authorization을 전달하지 않는 익명 클라이언트와 기존 공개 조회/RLS만 사용한다. 비공개·정지·삭제 등 기존 공개 조회가 거부한 프로필은 404, 조회/생성 실패는 본문 없는 503이다. 생성 응답은 no-store이며 진단 원문·사진 경로를 로그에 남기지 않는다. DB·인증·권한 변경 없음.
- 이미지 파일은 10MB 이하·입력 픽셀 수 제한을 적용해 정규화하고 사진을 자르지 않는 contain 방식으로 배치한다. 사용자 URL·파일 경로를 이미지 요청 인자로 받지 않는다.
- 자동 검사: 70개 묶음·431개 테스트와 TypeScript 검사 통과. 별도 테스트 DB가 필요한 통합 검사 7개 묶음은 미실행이다. 신규 검사 11개는 익명 조회·비공개 차단·오류 처리·사진 전체 표시·사진 없는 경우·공유 이미지 주소 변경을 포함한다.
- 실제 로컬 공개 자료로 PNG 1200×630 생성과 한글 이름/직군·사진 전체 표시를 확인했다. 실제 카카오톡 말풍선 검증은 카카오 로그인 이후 별도 확인해야 하며, 기존 카카오 캐시는 즉시 갱신을 보장하지 않는다.
- 커밋·병합·운영 배포와 운영 URL 검증 결과는 현황판 릴리스 기록에 별도로 남긴다. 기존 미완료 보안·개인정보 연락처 후속 작업은 유지한다.
