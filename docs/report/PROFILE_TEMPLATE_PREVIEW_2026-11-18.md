- 적용 범위는 공개 전문가 상세와 작성/읽기 전용 미리보기뿐이다. 공통 헤더·푸터와 다른 화면은 유지한다.

- 상세정보 꾸미기·게시판·영상 등록은 준비 안내만 제공한다. 수업 안내는 작성자 미리보기에서만 보인다. 저장 기능·DB·권한·결제 변경은 포함하지 않는다.
- 사용자 확정: 모바일 카드 축소, 홈 수업 안내(작성자만), 공개된 경력 날짜의 기존 표기 유지. 미리보기 구현 상태이며 운영 반영·병합·배포는 수행하지 않는다.

후속 작업(미착수, 각 범위 확정 필요): 상세정보 사진·글 저장, 게시판 글·사진/신고, 영상 유튜브 링크 등록, 홈 수업 안내 입력. 시안의 가짜 글·영상·수업·질문답변 자료는 코드나 DB에 포함하지 않았다. 기존 보안 후속 P0-10은 유지한다.

## 홈 이력 카드·지도 후속 조정

- 사용자가 요청한 홈 이력 요약을 실제 표시 항목이 있는 카테고리 최대 3개로 구성했다. 각 카드에 실제 제목 최대 3개와 해당 카테고리 전체 건수를 표시한다. 적은 항목은 있는 만큼만 표시하며 미인증 항목을 인증으로 표기하지 않는다.
- 기본 우선순위는 자격·면허, 교육·연수, 학력이며 빈 분류는 다른 입력 분류로 채운다. 카드 클릭은 공통 이력 탭으로 이동한다. 작성 미리보기에서는 기존 프로필 주소를 유지한다. 좁은 화면은 가로로 넘겨 읽는다.
- 현재 근무지에 공개 주소가 전달된 경우 기존 네이버 지도 컴포넌트를 홈에 한 번 표시한다. 주소 비공개/미등록 시 지도는 숨긴다. 현재 확인한 실제 공개 프로필에는 공개 근무지 주소가 없어 실제 지도 표시가 불가능하다. 기관명으로 주소를 추측하거나 비공개 주소를 조회·공개하지 않았다.
- TypeScript, 관련 5개 검사 묶음/30개 항목 통과. PC 실제 정보 카드·이력 탭 전환, 375px 가로 넘침 없음 확인. 공개 주소 전달/미전달 지도 분기는 대체 지도 컴포넌트 검사로 검증했고 이 조정에서 실제 지도 SDK 렌더링은 재검증하지 않았다.
- 앱 배포·원본 데이터 저장·게시·현황판 온라인 추가 게시는 수행하지 않았다.
