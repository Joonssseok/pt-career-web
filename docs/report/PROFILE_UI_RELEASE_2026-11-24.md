# 프로필 화면·전문분야 릴리스 · 2026-11-24

사용자가 누적 수정의 커밋·푸시·PR 병합·운영 배포와 현황판 게시를 승인했다. 아래는 릴리스 준비 시 확인한 범위이며, 최종 커밋·배포 결과와 운영 확인은 현황판의 같은 날짜 기록에서 이어 추적한다.

- 운동 분야 10개와 병원 근무를 홈·탐색·프로필 작성에 연결한다. 기존 두 분야 주소는 스포츠·컨디셔닝으로 연결하며, 선택 수와 의료기사 조건은 서버에서도 유지한다.
- 기본정보 입력은 밑줄 양식으로 통일하고 연락 항목명·입력·공개 선택을 같은 줄에 정돈한다.
- 프로필 카드의 병원 근무 설명은 짧은 커서·포커스 안내로 바꾸고, 공개한 근무지 이름 아래 작은 주소를 표시한다. 중복된 홈 근무지 영역은 제거한다.
- 가로 화면에서 오른쪽 내용이 왼쪽 카드보다 짧으면 주요 이력을 전체 공개 이력으로 펼친다. 휴대폰 세로 배치에서는 요약을 유지하며 이력 검색 결과는 중복하지 않는다.
- 개발용 시안은 운영 환경에서 열리지 않도록 유지한다. 비밀 설정·캐시·생성 파일은 커밋에서 제외한다.

## 검증

- 변경 관련 독립 검토: 10개 묶음 73검사, 타입·공백 검사 통과. 기존 소개 버튼 흐름을 되살리거나 새 저장 권한을 추가하지 않았다.
- 격리 PostgreSQL: 분류·병합·비공개·소유자·직군·한도·복구 129검사, 연락 공개 투영·소유자·스냅샷·복구 276검사 통과. 실제 회원 자료를 시험용으로 쓰지 않았다.
- 전체 Jest 실행: 113개 묶음 중 105개 통과, 919검사 중 853개 통과·66개 실패. 별도 시험 DB 자격이 필요한 62검사와 이전 릴리스에서도 실패한 소개 버튼 기준 3검사를 포함한다. 전체 실행 중 기본정보 저장 검사 1개도 실패했으나 해당 묶음 단독 재확인에서는 13개 모두 통과했다. 전체 검사 완료로 표시하지 않는다.
- 로컬 브라우저: 실제 공개 이력 14개 펼침, 검색 1건, 375px 요약 전환과 가로 넘침 없음을 확인했다. 입력 양식·연락 행·근무지 이름/주소·병원 근무 안내도 넓은 화면과 휴대폰 폭에서 확인했다.
- 실제 동시 클라이언트 실행 순서와 법률 적합성 검토는 완료로 표시하지 않는다. 기존 보안 후속 P0-10 상태도 유지한다.

## 기존 DB 연결 확인

이미 승인·적용된 `20261123151048 / specialty_categories`와 `20261124015753 / profile_contact_location_name`을 서버 이력에서 확인했다. 이번 릴리스에는 같은 데이터 전환을 다시 실행하지 않는다. 준비 파일 시각과 서버 적용 시각 차이는 앞선 개별 보고서에 남아 있다.

배포 문제 발생 시 앱은 이전 운영 배포로 되돌릴 수 있다. 분류 복구는 이후 사용자 변경과 충돌할 수 있으므로 자동 실행하지 않으며, 기존 데이터와 비공개 백업을 보존한다.
