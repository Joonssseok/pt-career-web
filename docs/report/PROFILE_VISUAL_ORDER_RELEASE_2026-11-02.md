# 프로필 공개 전 편집·순서 저장 반영 보고

- Status: 릴리스 검증 완료, 배포 결과는 개발 현황판에 기록
- Date: 2026-11-02 KST
- Authority: 사용자 요청 — 수정사항 커밋·병합·배포 및 현황판 갱신. 운영 DB는 본인 프로필 순서 저장 범위만 별도 승인.

## 변경

- 공개 전 확인에서 실제 공개 프로필 레이아웃을 재사용한다. 항목별 증빙 첨부 팝업, 외부 클릭 닫힘, 제외 확인 및 우측 첨부파일·실제 심사 상태 표시를 제공한다.
- 전문분야는 최상단 고정. 나머지 섹션과 개별 이력은 왼쪽 손잡이로 끌어 이동한다. 이동 중 카드가 포인터를 따라 움직이며 놓을 위치를 표시한다. 클릭 이동 메뉴는 제거했다. 키보드 방향키도 지원한다.
- 정렬 순서는 VersionContent.order에 저장하고 재조회한다. 기존 save_profile_version의 owner_id = auth.uid() 검증과 읽기 RLS를 유지한다. 다른 프로필의 순서·다모아 원본·공개 여부는 변경하지 않는다.
- 하단은 동일한 테두리 서식의 '프로필 저장', '공개프로필 업로드'로 정리하고 복제 버튼을 제거했다.
- 자격 증빙 공개 선택 코드와 접근 제한을 포함하되, 별도 운영 DB 변경 없이 기존 비공개 자격증 저장은 계속 가능하도록 호환성을 유지한다.

## 운영 DB

profile_order_persistence만 적용. 기존 콘텐츠 검증을 유지하면서 선택적 order 필드를 허용한다. 중복·비문자열·과대 입력은 거부한다. 기존 데이터나 접근 정책은 변경하지 않는다. 이전 license_evidence_public_choice 및 profile_version_search_sync 마이그레이션은 미적용 유지.

## 검증

- TypeScript 검사 통과.
- 프로필 정렬/복원, 공개 전 편집, 자격 증빙 API/선택/기존 저장 호환성 등 테스트 21개 통과.
- 운영 빌드 검증.
- 로그인한 로컬 브라우저: 섹션 변경 → 프로필 저장 → 새로고침 → 공개 전 확인에서 순서 유지 확인. 운영 DB 저장 값과 다른 프로필의 순서 미변경 확인.
- 기존 데이터 검증 통과 및 올바른 순서 허용, 중복/잘못된 순서 형식 거부를 운영 읽기 쿼리로 확인.

## 범위와 제한

- 순서와 기존 프로필 내용은 서버 저장된다. 새 첨부·심사 요청·항목 제외 선택은 여전히 미리보기이며 전송/영구 저장하지 않는다. 화면에 이를 안내한다.
- 대표 프로필 실제 공개 전환은 기존 보류 유지. LIVE_PROFILE_PUBLISH_ENABLED는 false다.
- 인증파일 공개용 별도 운영 DB 변경은 승인 범위가 아니므로 적용하지 않았다. 기존 증빙 원본은 비공개 유지.
- 롤백 시 앱을 이전 버전으로 되돌리고 이미 저장된 order는 보존한다. 이 마이그레이션은 이전 형식도 계속 허용한다.
