# 프로필 와이어프레임 미리보기

## 2026-11-18 · 사용자 요청에 따른 취소 범위

- 배치 편집 프로그램만 유지한다. 대표 경력 비교·콘텐츠형 프로필·실제 프로필 연결 미리보기와 그 전용 구성요소·테스트·문서는 제거했다.
- 공통 공개 프로필에 임시 추가했던 대표 콘텐츠 삽입 옵션을 제거해 기존 코드로 복원했다. 배치 편집기의 콘텐츠 미리보기 링크도 제거했다.
- 배치 편집·영역 이름 수정·추가/삭제·중앙선·되돌리기·브라우저 저장 및 복원 기능은 유지한다. 기존 localStorage 키와 저장 형식은 변경하지 않았다.
- 기존 자료·DB·실제 프로필·배포는 변경하지 않는다. 이번 작업과 무관한 기존 변경은 보존한다.

- 주소: `/preview/profile-wireframe` (개발 환경 전용)
- 글·사진·실제 계정 자료를 사용하지 않고 영역 이름만 표시한다.
- 같은 11개 영역을 A 균형형 / B 프로필 분리형 / C 대표 콘텐츠형 / D 모듈 조합형으로 비교한다.
- 한눈에 비교, 개별 배치, PC·모바일 표시를 전환한다.
- 개별 배치에서 직접 배치: 드래그 이동·모서리 크기 조절, 방향키 조절, 되돌리기·초기화.
- 영역 이름은 두 번 클릭 또는 F2로 수정하고 Enter/바깥 클릭으로 적용, Esc로 취소한다. 빈 이름은 기존 이름을 유지한다.
- 새 칸 추가 시 아래 빈 공간에 배치하고 이름 입력으로 이동한다. 세로 중앙선은 표시·숨김 가능하다.
- 각 칸 오른쪽 위 ×로 삭제하며 되돌리기로 이름·위치·크기까지 복원한다. 실제 자료 삭제와 무관하다.
- ‘배치 저장’으로 현재 배치 한 개를 같은 주소·브라우저의 localStorage에 저장한다. 영역 이름·위치·크기·추가·삭제, 선택한 A~D 배치, PC/모바일 모드, 중앙선 설정을 보존한다.
- 새로고침 시 마지막 저장 배치를 자동 복원하며 ‘저장한 배치 불러오기’로도 복원한다. 저장하지 않은 변경은 복원하지 않는다. 다른 배치를 저장하면 이전 저장 한 개를 덮어쓴다.
- 복원 시 형식·중복 ID·수치 범위 등을 검증하며 손상된 저장 내용을 자동 삭제하지 않는다. 저장소 접근·용량 오류는 사용자에게 안내하고 편집 내용을 유지한다. 서버 전송·로그인 계정 동기화 없음. 브라우저 데이터 삭제나 다른 주소에서는 저장을 이용할 수 없다.
- 기존 공개 프로필, 데이터, 인증·심사·공개 범위에 변경 없음. 배포하지 않음.
- TypeScript 검사와 편집 관련 7개 테스트 통과. 브라우저에서 이동한 위치를 저장하고 실제 새로고침 후 같은 위치로 복원됨을 확인했다. 재시작 시 추가 칸 ID 충돌, 빈 배치 복원, 잘못된 저장 내용, 저장 실패도 테스트했다.
