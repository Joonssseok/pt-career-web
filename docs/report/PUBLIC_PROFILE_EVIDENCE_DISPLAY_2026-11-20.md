# 공개 프로필 사진·이력 증빙 표시 수정

- 전문가 목록 사진을 전체 표시/상단 정렬로 바꿔 정사각형 영역에서 윗머리를 잘라내지 않는다. 남는 좌우 공간은 기존 카드 배경으로 표시한다.
- 이력 카테고리의 건수·인증 요약 문구를 제거했다. 왼쪽 프로필 요약과 이력 탭 숫자는 별도이며 유지한다.
- 인증 표시는 16px로 줄이고 항목명 바로 옆에 배치했다. 오른쪽으로 밀던 스타일을 제거했다.
- 공개 승인된 증빙이 있으면 항목명 클릭으로 팝업을 연다. 파일명 링크 목록은 제거했고 여러 자료는 이전/다음으로 넘긴다. 공개 파일이 없는 항목은 제목과 인증 표시만 유지한다.
- 기존 공개 증빙/면허 서류 경로를 그대로 사용해 워터마크·공개 승인 검사를 유지한다. 팝업 뷰어는 열었을 때 파일을 요청하며 닫기/전환 시 요청과 임시 URL을 정리한다. 홈 썸네일은 같은 공개 경로에서 지연 로딩한다. 원본·DB·권한·공개 범위는 변경하지 않았다.
- 실제 로컬 목록 사진과 이력 화면을 확인하고 선수트레이너 제목 클릭 후 공개 증빙 이미지 로딩을 확인했다. 관련 표시·편집·워터마크 테스트 및 타입 검사를 수행했다. 실제 휴대폰 확인은 미수행이다.

현재 로컬 미리보기 상태다. 커밋·푸시·병합·배포 및 온라인 현황판 게시는 수행하지 않았다.

## 링크 색상과 기관명 간격

- 공개 증빙을 여는 항목명은 사용자 후속 요청에 따라 기존 항목과 같은 검정(slate-900)으로 표시하고 마우스를 올리면 회색(slate-500)과 밑줄로 구분한다. 비공개 자료만 있는 항목명은 기존 글자색을 유지한다.
- 링크 버튼의 최소 높이44px가 기관명을 밀어내던 원인을 수정했다. 시각적 줄 높이는 일반 제목과 동일하게 두고 별도의 투명 영역으로 클릭 높이를 유지한다.
- 현재 프로필의 14개 항목 모두 브라우저에서 제목 높이24.5px/기관명까지 간격2px로 동일함을 확인했다. 링크·일반 제목 모두 같은 기준이다. 긴 항목명이 줄바꿈되면 그 마지막 줄 아래부터 같은 간격이 적용된다.
- 로컬 미리보기만 갱신했으며 배포하지 않았다.

## 화면에 맞춘 팝업·홈 증빙 모아보기

- 이미지 팝업은 최대900px 폭·820px 높이(작은 화면에서는94vw·90dvh) 안에서 이미지 전체를 object-contain으로 표시한다. 이미지 원본 크기로 세로 스크롤하지 않는다. 기존 PDF는 같은 영역의 브라우저 PDF 뷰어에서 페이지 맞춤으로 연다.
- 홈 주요 이력 아래에 공개 승인된 파일만 좌우로 넘기는 증빙 썸네일 목록을 추가했다. 썸네일 클릭 시 해당 자료부터 팝업을 열고, 이전/다음으로 다른 이력의 공개 자료도 이어서 본다.
- 현재 공개된 이력 제목만 자료 이름으로 사용하고 제목이 숨겨졌으면 공개 카테고리로 대체한다. 비공개 파일·숨긴 활동의 새 노출은 없고, 공개 승인·워터마크 API를 그대로 쓴다. 공개 파일이 없으면 목록 영역을 생략한다.
- 관련5묶음86검사·타입 검사 통과. 실제 로컬 프로필에서 공개 증빙9건 목록 및 가로 넘김을 확인했다. 서버·DB·권한 변경이나 운영 배포는 하지 않았다.

## 사진만 자동 이동하는 모션

- 후속 요청으로 제목·설명·이동 버튼·스크롤바를 없애고 사진만 천천히 왼쪽으로 이어서 흐르게 했다. 같은 사진 묶음을 반복해 끝에서 자연스럽게 이어진다.
- 사진 위에 커서를 올리면 정지하고 벗어나면 재개한다. 키보드 포커스/팝업 중에도 정지하며 모션 줄이기 설정에서는 자동 이동을 끈다. 복제 묶음은 접근성 트리와 탭 순서에서 제외한다.
- 브라우저에서 영역 내 텍스트 없음, 커서 진입 시 paused/이탈 시 running을 직접 확인했다. 관련 컴포넌트 검사와 타입 검사 통과. 로컬 미리보기만 반영했다.

## 후속 배포 요청

사용자 확인 후 사진 표시·이력 요약 제거·인증 표시·항목명 팝업·기관명 간격·사진 자동 이동을 같은 범위로 커밋·푸시·병합·배포한다. 관련86검사·타입 검사와 기존 공개 경로 유지 확인. DB·권한·파일·심사 상태는 변경하지 않는다. 운영 결과와 실제 휴대폰 확인 등 남은 작업은 현황판에 구분해 기록한다.

## 홈 영역 순서 · 후속 로컬 수정

- 홈을 설명 → 상세정보 → 이력 → 게시판 → 영상 → 근무지 순서로 정리했다. 상세정보에는 기존 글·사진·활동 갤러리를 재사용하고, 상세소개 문서의 영상은 홈에서는 영상 영역으로 분리한다. 별도 상세정보 탭은 기존 글·사진·영상 구성을 유지한다.
- 게시판은 아직 저장 기능이 없어 작성자 미리보기의 준비 영역만 두며 방문자에게 빈 영역은 노출하지 않는다. 영상이나 상세정보가 없으면 해당 영역을 생략한다. 근무지·지도는 마지막이다. 기존 수업 안내 준비 영역은 작성자 미리보기 상세정보 아래로 옮겼다.
- 현재 실제 공개 정보에는 영상이 없어 브라우저에서 설명·상세정보·이력·근무지 순서로 확인했다. 별도 가상 문서 검사에서는 6개 영역 전체 순서 및 상세정보 탭의 기존 영상 보존을 확인했다. 갤러리 이동 대상 ID는 홈/상세정보에서 구분해 중복하지 않는다.
- 이 후속 수정은 아직 커밋·배포하지 않았다. DB·저장된 소개 문서·사진·공개 범위 변경 없음.

## 홈 상세정보 제거·게시판/영상 챕터 · 최신 로컬 기준

- 사용자가 홈의 상세정보를 제거하고 게시판·영상은 홈/탭 화면 구성만 먼저 미리보기로 진행하도록 선택했다. 홈의 최종 순서는 설명 → 이력 → 게시판 → 영상 → 근무지다. 별도 상세정보 탭의 기존 글·사진·영상은 유지한다.
- 홈은 기록된 내용이 있는 챕터만 표시하며, 비어 있으면 제목과 빈 공간까지 생략한다. 게시판·영상 탭은 유지하고 해당 탭에서만 빈 상태를 안내한다. 실제 공개 영상이 있으면 기존 승인된 상세소개 영상과 채널 링크를 사용한다. 가상 글·영상·건수는 생성하지 않는다.
- 작성자 미리보기에만 글쓰기·영상 추가 버튼을 두고 기존 준비 안내를 연다. 작성·등록·저장·DB 연결은 이번 범위가 아니다. 홈 전체 보기는 해당 탭으로 이동하며 작성자 미리보기의 URL은 유지한다.
- 로컬 실제 화면에서 홈 상세정보 없음 및 게시판/영상 탭 전환을 확인했다. 이 변경은 미배포 상태이며 기존 개인정보·권한 후속 작업을 완료한 것으로 처리하지 않는다.
- 빈 홈 챕터 생략·기록된 영상 표시·탭 이동을 포함한 관련 3묶음 27검사와 타입 검사를 통과했다. 게시판·영상이 없는 프로필의 홈은 설명 → 이력 → 근무지만 표시한다.
