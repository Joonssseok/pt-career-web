# 정식 도메인 프로필 QR 복구

2026-11-16 KST. 정식 도메인 마련 후 QR 복구 요청에 따른 변경.

## 구현

- 공유 관리와 공개 프로필 기본 공유 주소를 https://ptcareer.co.kr/experts/{프로필ID} 로 통일한다. 프로필 ID는 대표 버전 ID와 구분되는 기존 소유자 프로필 식별자다. 이름·소개·대표 버전이 바뀌어도 같은 주소를 사용한다.
- 기존 공개 여부·승인·게시 확인 이후에만 QR과 명함을 제공한다. 생성 중 프로필이 바뀌면 이전 QR을 다시 표시하지 않는다.
- QR 보기, PNG 복사, PNG 저장 링크와 기본/블루 명함 QR을 제공한다. 이미지 복사를 지원하지 않는 기기는 저장 링크를 안내한다. 가상 미리보기에서는 복사·저장·전송을 실행하지 않는다.
- QR은 브라우저 안에서 생성한다. 외부 QR 서비스 요청·새 DB/인증/공개 권한 변경·원본 자료 변경은 없다. 기존 비공개·탈퇴 안내 및 재공개 경로를 유지한다.
- 최대 1024px PNG, 흑백과 사방 여백을 유지한다. 모바일 공유 영역의 최소 너비로 인한 가로 넘침을 함께 수정했다.

## 검증

- 일반 회귀 68개 묶음 430개 항목, 타입 검사 통과. 별도 로컬 DB가 필요한 기존 통합 테스트 6개 묶음은 제외했다. 저장 링크 수정 후 인접 3개 묶음 16개 항목과 타입 검사 재통과.
- 실제 생성 PNG를 1024/256/240px로 해독해 동일한 정식 도메인 주소가 포함되는지 확인했다.
- 로그인한 실제 로컬 공유 화면에서 QR 표시와 PNG 클립보드 복사 성공, 기본 명함 저장 확인. 실제 내려받은 명함 1050×600 PNG의 QR을 해독해 주소가 일치함을 확인했다.
- 실제 브라우저 표시 QR PNG를 별도 산출물로 추출해 해독했다. 단독 QR 저장 링크는 PNG Blob과 download 속성을 검증했으나, 내장 브라우저의 다운로드 완료 이벤트와 다운로드 폴더 파일은 확인하지 못했다. 이를 실제 파일 저장 완료로 표시하지 않는다.
- 390px 요청 폭에서 QR 창이 화면 안에 들어가며 페이지 가로 넘침 없음 확인. 모바일 실기기 카메라/다운로드 동작은 미검증.
- 사용자 운영 배포 요청에 따라 이 변경을 커밋·푸시·병합 후 배포한다. 최종 PR·운영 READY 결과는 배포 기록으로 확인한다. 정식 도메인 등록 갱신과 기존 프로필 경로를 유지해야 인쇄 QR을 계속 사용할 수 있다.
