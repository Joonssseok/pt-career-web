# 소개·상세소개 편집 및 미디어 배포 · 2026-11-18

사용자가 소개/상세소개 편집기와 후속 사진 크기·자르기 수정의 커밋·푸시·병합·배포 및 현황판 기록을 요청했다.

## 배포 범위
- Tiptap 공식 Simple Editor를 소개/상세소개에 적용하고 허용된 글 서식을 기존 초안 저장·공개 전 확인·게시 표시와 연결한다.
- 상세소개 사진/GIF/MP4/WebM/유튜브 배치, 이동·삭제·실행 취소 및 기존 비공개 첨부파일 저장 절차를 연결한다.
- Cropper.js 2.3.1의 선택 영역·손잡이·비율 선택을 적용한다. 원본 파일을 덮어쓰지 않고 너비/자르기 영역만 문서에 저장한다.
- 실제 작성창 첫 진입 시 편집기·팝업 스타일 누락을 수정한다. 개발 전용 독립 미리보기는 운영에서 접근되지 않는다.
- 기존 소유자/공개/첨부 참조 검사, 파일 한도, 별도 게시 흐름을 유지한다. 임의 HTML/외부 이미지/임의 iframe은 허용하지 않는다.

## 검증과 한계
- TypeScript와 전체 84묶음/665항목 통과. 별도 로컬 DB가 필요한 기존 통합 묶음 6개는 제외했다.
- 독립 SQL 19/42검사, 실제 연결 DB의 트랜잭션 저장/재조회 후 전부 롤백 및 기존 자료 보존 검증은 각 기능 보고서에 기록했다.
- 브라우저 실제 작성창/독립 미리보기, PC/모바일 폭, 기존 본인 사진 표시, 자르기 적용·재열기·취소·원본 복원 확인. 운영 업로드/게시/삭제를 시험 목적으로 수행하지 않는다.
- 실제 모바일 기기의 터치/펜 입력 및 코덱별 영상 재생·고부하 검증은 남아 있다.

## 적용과 복구
- 저장 검증/공개 함수의 호환 확장 3개는 이전 사용자 요청 범위에서 적용됐으며 이번 배포에서 재적용하거나 추가 권한을 부여하지 않는다.
- 복구는 앱을 직전 운영 릴리스로 되돌리는 방식이다. 새로 저장된 서식/미디어/영역 정보나 원본을 삭제하지 않고 DB의 호환 검증 확장은 유지한다.
- PR·배포 식별자와 실제 운영 확인 결과는 배포 완료 후 현황판 릴리스 기록에 연결한다. 기존 보안/개인정보 문의 연락처 후속 항목은 유지한다.
